# Markdown Instructions

- Use ATX-style headings (`##`) — never underline-style (`===`)
- Leave a blank line before and after headings, lists, and code blocks
- Use fenced code blocks with a language tag: ```python ... ```
- Use relative links within the repo, full URLs for external references
- Use `[descriptive text](link)` — never bare URLs in prose
- Use `-` for unordered lists, `1.` for ordered lists (consistent)
- Keep line length ≤ 100 characters for readability in diffs
- Tables use pipes and dashes with alignment markers where helpful
- Use `**bold**` for emphasis, `` `code` `` for inline code/references
