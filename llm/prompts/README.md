# LLM Prompts

Reusable prompt templates for specific tasks. Copy-paste these into LLM chats as needed.

## Format

Each file is a self-contained prompt. Use `{{PLACEHOLDER}}` syntax for parts that need filling in.

## Examples

- `code-review.md` — prompt for reviewing a diff or PR
- `explain-code.md` — prompt for explaining unfamiliar code
- `debug-issue.md` — structured debugging prompt
