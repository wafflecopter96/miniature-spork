First infer:

- What the options are
- The likely purpose behind them
- Whether they aim to accomplish the same goal
- The intended audience, use case, priorities, and constraints
- The criteria that matter most for judging success

- One option is the clear winner
- One has a modest or marginal advantage
- The options are effectively tied
- Each is better for a different use case
- They are not sufficiently comparable

- Principal strengths
- Principal weaknesses
- Where it exceeds the others
- Where another option exceeds it

4. **Strengths and weaknesses** — brief bullets for each option
5. **Where each option wins** — the specific dimensions or situations in which each is superior
6. **Recommendation** — which to use, whether useful elements should be combined, and the smallest changes that would improve the preferred option

Be direct and proportionate. Do not manufacture differences, force a winner when the options are effectively equal, or reward added length unless it materially improves the intended result.
