# Architecture

## Execution model

The tracker is intentionally a **run-once batch collector**:

```text
start
  -> load and validate configuration
  -> resolve calendar-range/rolling/explicit departure dates
  -> calculate request budget
  -> query configured providers
  -> preserve raw responses
  -> normalize offers
  -> apply exact-flight/airline filters
  -> write normalized observations
  -> optionally insert exact raw responses into PostgreSQL
  -> write manifest
  -> complete PostgreSQL run state
  -> write _SUCCESS
  -> exit
```

Scheduling belongs to Airflow, not the application.

## Why this boundary

Flight-price collection does not require a continuously resident process. Keeping the
application run-once provides:

- deterministic collection windows
- natural retries
- easy Docker/Kubernetes parity
- lower idle resource use
- simpler deployment and shutdown behavior
- explicit success/failure semantics

## Components

### Configuration

`config.py` parses environment settings and `tracked_routes.yaml`.

The YAML defines *what* to collect. Environment variables define *how/where* the same
image executes.

### Provider adapters

`collectors/serpapi.py` and `collectors/duffel.py` own provider-specific request/response
logic. They return the same `PriceObservation` domain model.

Production uses FastFlights only. A FastFlights failure is recorded against that
logical request and collection continues according to the run failure policy; it
does not invoke SerpApi. The SerpApi adapter remains available for explicit,
backward-compatible provider selection.

Nothing outside an adapter should depend on a provider's native schema.

### Filtering

Provider-side filters are used when available to save quota and response volume. The
canonical filtering layer is still applied after normalization, especially for exact
flight numbers that an upstream search API may not support directly.

### Landing zone

The landing zone is the durable system-of-record for collection output.

The collector always keeps raw provider JSON before considering the run complete.
Normalized NDJSON is derived from those raw responses.

### PostgreSQL

PostgreSQL is an optional raw source sink. `STORAGE_MODE=both` keeps the existing
raw/normalized files and inserts exact provider response JSON into
`raw.json_documents`. No normalized relational tables are created in this
phase. Kubernetes explicitly allows only the resolved analytics PostgreSQL
service and port in addition to DNS and the HTTP proxy.

## Idempotency

Airflow should set:

```text
RUN_ID=<logical UTC timestamp>
```

The run directory becomes deterministic. When `_SUCCESS` already exists and
`SKIP_SUCCESSFUL_RUN=true`, a retry exits without collecting a second observation.

Within PostgreSQL, `(producer, run_id, document_key)` is immutable. An identical
checkpoint replay is accepted; changed content under the same identity fails.

## Failure semantics

A provider/date request is one collection unit.

- Successful raw responses are written immediately.
- Failures are accumulated into `manifest.json`.
- `_SUCCESS` is emitted only when the run satisfies the configured failure policy.
- `_FAILED` marks an unsuccessful run.
- With `FAIL_ON_PARTIAL=true`, any exhausted provider request causes a non-zero process exit.
- A FastFlights failure is not recovered by a second provider attempt.
- PostgreSQL run status is completed before filesystem `_SUCCESS`, so a raw
  landing failure cannot produce a complete file run.

This preserves evidence from partial runs while preventing downstream consumers from
mistaking them for complete snapshots.

## Deterministic logical-run contract

`RunContext` separates immutable logical identity (`RUN_ID`, `LOGICAL_AT`, `ANCHOR_DATE`) from `attempt_started_at`. The latter is observability-only. Durable runs are keyed by `/app/output/flight-price-tracker/collection_date=<DATE>/run_id=<RUN_ID>/`; the immutable `run_definition.json` binds that ID to logical time, anchor, application version, tracking-config SHA256, canonical-plan SHA256, and complete request definitions. A mismatch fails before provider calls.

Each canonical request has a SHA256 `request_key` and its own checkpoint directory. Completed checkpoints are validated and reused on retry; only missing units are fetched. Provider observation timestamps remain the actual fetch timestamps. Final normalized NDJSON is rebuilt from checkpoints in deterministic order, and `_SUCCESS` is published last and makes the run immutable.

# Cost and Request Control

Production uses FastFlights only. FastFlights failures do not trigger an
automatic SerpApi fallback, and valid empty searches land as successful empty
FastFlights responses.

Before any provider call, `MAX_REQUESTS_PER_RUN` is compared against the
worst-case provider attempt count:

```text
sum across resolved searches:
  every planned provider search -> 1 provider-budget unit
```

For a FastFlights-only plan, `maximum_provider_attempts` equals
`request_count`. The production ceiling remains `MAX_REQUESTS_PER_RUN=5000`.

The `plan` command reports logical `request_count` and
`maximum_provider_attempts`. Run manifests report actual `provider_attempts`
and a compatibility `fallbacks` field, which remains empty for FastFlights-only
runs. HTTP retries remain separate: `REQUEST_RETRIES`
controls additional transport attempts and can increase actual traffic and
provider quota usage. Set it to zero when one HTTP attempt per provider is needed.

Explicitly listing both `fast_flights` and `serpapi` creates two independent
planned provider searches; the production configuration lists only FastFlights.

FastFlights requires no API key. The SerpApi credential is validated only when
`serpapi` is explicitly configured. Database write failures do not trigger
another provider request. Failed-run orchestration retries currently refetch all
planned searches and can consume additional quota.

`serpapi_deep_search` remains available for explicit SerpApi selection. Enable
it only after reviewing the provider's current latency and cost implications.


===== FILE: docs/DATA_CONTRACT.md =====

# Data Contract

## PostgreSQL landing

All durable output lives in `raw.json_documents` and `raw.ingestion_runs`.
There are no filesystem checkpoints or normalized output files.

`payload` is PostgreSQL `json`, not `jsonb`. The landing layer retains JSON
whitespace, key order, unknown fields, and numeric spelling. Payload SHA-256 and
byte length are computed from the exact UTF-8 JSON submitted to PostgreSQL.

| Provider | Payload | Stream |
| --- | --- | --- |
| fast_flights | Original JSON array extracted from the Google Flights ds:1 script | flight.fast_flights.search-response |
| serpapi | Original JSON response object | flight.serpapi.search-response |
| duffel | Original JSON response object | flight.duffel.search-response |

For fast-flights, only the surrounding HTML and JavaScript callback are removed.
The adapter uses the data boundary from fast-flights 3.1.0 and validates JSON,
the flight-list location, and search metadata. Unknown fields are preserved.
Missing scripts, malformed data, HTTP errors, and transport failures fail the
FastFlights collection unit; they never trigger an automatic SerpApi fallback.
A structurally valid empty flight list is a successful empty FastFlights response.
SerpApi's documented no-results error response remains available only for an
explicit SerpApi search.

## Identity and metadata

Document keys remain `request/<request_key>`, keyed to the planned search.
For production FastFlights-only collection, the actual and planned provider are
both `fast_flights`.

Metadata includes the original request definition, actual provider,
compatibility `fallback_from` and `primary_error_type` fields (null for a
successful FastFlights response), timestamps, HTTP status, allowlisted
HTTP headers, and `raw_record_count` where available. Headers describe the
original HTTP response, so fast-flights can report `text/html` while the landed
payload is JSON. Provider credentials are excluded.

The manifest records logical completed/failed requests, `provider_attempts`,
and the compatibility `fallbacks` field, which is empty for FastFlights-only
collection.
`provider_attempts` excludes retries inside the HTTP transport.
A database failure stops collection without triggering another provider request.

## Downstream modeling

fast-flights and SerpApi collection do not depend on normalization. Legacy
observation counts can therefore be zero despite a nonempty raw flight list.
`raw_record_count` is the source itinerary count, not a filtered count.

Search constraints are sent upstream; raw data is never filtered before landing.
Apply flight-number filters and validate upstream constraint compliance downstream.
The raw fast-flights array is an undocumented upstream structure and can change;
the dependency is pinned so parser/query changes can be reviewed deliberately.

Derive itinerary, segment, price, currency, carrier, fare, and booking-window
models downstream, retaining provider, search context, and collection timestamp.
Do not join solely on flight number: it recurs across dates and can represent
different fares and codeshares.

# Deployment

## Prerequisites

Common:

- reachable centralized HTTP CONNECT proxy if `REQUIRE_PROXY=true`
- complete raw PostgreSQL connection settings (or `DATABASE_URL`)
- durable landing-zone directory
- immutable built image

Docker:

- external `proton-egress` Docker network
- proxy container/service reachable as `proton-egress:8888`
- shared landing-zone host path

Kubernetes:

- existing `private-apps` namespace and `registry-runner` service account
- `flight-price-tracker-config` ConfigMap
- existing `proton-egress` Service + EndpointSlice
- existing bound `tracker-output` RWX PVC
- existing `analytics-postgres-ingest` Secret containing `RAW_POSTGRES_HOST`,
  `RAW_POSTGRES_PORT`, `RAW_POSTGRES_DATABASE`, `RAW_POSTGRES_USER`, and
  `RAW_POSTGRES_PASSWORD`
- application image available to the worker node

## Docker validation

```bash
cp .env.example .env
# populate keys and host output path as needed

docker compose -f deploy/docker/docker-compose.yml build
docker compose -f deploy/docker/docker-compose.yml run --rm tracker validate-config
docker compose -f deploy/docker/docker-compose.yml run --rm tracker plan
docker compose -f deploy/docker/docker-compose.yml run --rm tracker collect
```

## Kubernetes preparation

The cluster-wide namespace, registry pull secret, proxy endpoint, and shared PVC already
exist. Apply only the application ConfigMap:

```bash
kubectl apply -f deploy/k8s/base/configmap.yaml
```

Verify prerequisites before running anything:

```bash
kubectl -n private-apps get pvc tracker-output
kubectl -n private-apps get configmap flight-price-tracker-config
kubectl -n private-apps get secret analytics-postgres-ingest
```

It must be `Bound`.

Verify proxy name resolution/reachability from a disposable test pod or a controlled
validation job before enabling scheduled collection.

Airflow's KubernetesPodOperator supplies the digest-pinned image and full hardened Pod
template; no independent CronJob is enabled in production. The fail-closed
policy permits DNS, the Proton proxy, and only the resolved raw PostgreSQL
service/port.

## Scheduling ownership

Choose one scheduler:

### Airflow

Preferred when this data feeds an existing data pipeline, needs dependencies, retries,
backfills, or downstream dbt work.

Do not enable an independent Kubernetes CronJob for the same target/cadence unless
duplicate provider requests are intentional.

## Airflow backend switch

The production DAG uses:

```text
FLIGHT_COLLECTION_OPERATOR=docker
```

or:

```text
FLIGHT_COLLECTION_OPERATOR=kubernetes
```

Kubernetes forces `STORAGE_MODE=both` and required raw PostgreSQL landing.
Docker remains file-only by default because the Docker proxy network cannot
reach a Kubernetes ClusterIP. Both backends keep the same file contract.

## Production image workflow

1. Build once.
2. Run tests.
3. Push image.
4. Record digest.
5. Deploy the same digest to Docker/Airflow and Kubernetes/Airflow.
6. Change configuration independently from image code where practical.

## Backfills

A historical API backfill is not assumed. To reproduce a *collection run* with a past
anchor date:

```bash
python -m flight_price_tracker plan \
  --config config/tracked_routes.yaml \
  --anchor-date 2026-08-28
```

That changes which future departure dates are searched today; it does not recreate prices
that existed on August 28. Historical prices only exist if they were actually observed
and persisted at that time.

## Installed Airflow schedule

`flight_price_tracker_example_routes` runs at `0 8,20 * * *` in
`America/Toronto` (08:00 and 20:00), with `catchup=False`, one active run, and an end date of
2027-09-01. The DAG remains paused until PostgreSQL connectivity and provider
consumption are approved.

## Logical-run values

Airflow is the canonical production scheduler. Both DockerOperator and
KubernetesPodOperator pass exactly `RUN_ID`, `LOGICAL_AT`, and `ANCHOR_DATE`, derived
from `dag_run.logical_date or dag_run.start_date` for Airflow 3 manual-run compatibility.
The run ID and timestamp use UTC; the anchor date uses `America/Toronto` so an evening
run does not prematurely discard the current local departure date.

## Hardened KPO contract

The DAG imports `FlightTrackerSettings` and `kubernetes_pod_template()` from `orchestration/airflow/flight_tracker_task.py`. The reusable Pod template mirrors the standalone Job: output preflight, fail-closed Proton egress init, restricted `base` container, RWX `/app/output`, read-only tracked routes, bounded `/tmp` and `/run`, explicit resources, dedicated service account with token automount disabled, and role-based `worker|worker-preferred|control-plane|any` placement.

`worker-preferred` gives `k8s-worker-01` a weight-100 scheduling preference
while retaining the narrow control-plane taint toleration as fallback. It
applies to new Pods; Airflow must retry a task interrupted by node loss.

# Network and Storage Policy

This repository follows the same portability principle as the existing scraper pattern:
the application must not care whether it runs on the local Docker host or a Kubernetes
worker.

## Stable container contract

Both execution modes use:

```text
configuration: /app/config/tracked_routes.yaml
output root:   /app/output/flight-price-tracker
proxy:         http://proton-egress:8888
command:       python -m flight_price_tracker collect
UID/GID:       1000/1000
```

Only the orchestrator's mounting/network implementation changes.

## Docker

The Compose example joins an existing external Docker network called `proton-egress`.
The central proxy is expected to be resolvable as:

```text
proton-egress:8888
```

Durable storage is a host bind mount:

```text
/var/lib/tracker-data -> /app/output
```

The tracker is not allowed to depend on anonymous Docker volumes.

## Kubernetes

### Proxy

Kubernetes receives the same logical hostname through:

```text
Service proton-egress
        +
EndpointSlice -> externally reachable proxy address
```

The application still sees:

```text
http://proton-egress:8888
```

No application code contains the proxy host's physical IP.

### Fail-closed egress

The hardened KubernetesPodOperator template uses an init container in the pod network namespace to set:

```text
OUTPUT policy = DROP
allow loopback
allow established/related
allow DNS
allow TCP to proton-egress:8888
allow TCP to the resolved analytics PostgreSQL service and configured port
```

The main application container itself has no Linux capabilities and runs read-only as
UID 1000.

This protects against accidentally sending a provider request directly to the internet
when proxy variables are missing or ignored.

`REQUIRE_PROXY=true` adds an application-level configuration check as a second guard.

### Storage

The existing `private-apps/tracker-output` PVC is `ReadWriteMany` and is backed by the
centralized `/var/lib/tracker-data` NFS export. Both runtimes write the dataset at:

```text
canonical host/NFS: /var/lib/tracker-data/flight-price-tracker
physical SSD:       /srv/landing/trackers/flight-price-tracker
container:          /app/output/flight-price-tracker
```

```text
Docker host                     Kubernetes worker
     |                                |
bind mount                         RWX PVC
     |                                |
     +--------- central landing zone -+
```

There is intentionally **no worker-node-local fallback**. If the PVC cannot bind/mount,
the Kubernetes job should not start.

The example static PV is kept separate because the NFS server address is infrastructure
specific.

## PostgreSQL and strict egress

Kubernetes dual-writes exact raw provider JSON to the analytics PostgreSQL
service. The kill-switch resolves `RAW_POSTGRES_HOST` after enabling cluster
DNS, permits only that IPv4 address and `RAW_POSTGRES_PORT`, then applies the
default DROP policy. The service hostname is in `NO_PROXY` so database traffic
is never sent to the HTTP proxy.

Docker remains file-only by default: its internal `proton-egress` network does
not route to a Kubernetes ClusterIP. A Docker caller may enable PostgreSQL only
when all structured connection settings point to a database reachable from
that network.

## Secrets

Never place API tokens in:

- image layers
- tracked YAML
- ConfigMaps
- command-line arguments
- repository `.env`

Production FastFlights collection requires no provider credential. The dormant
direct SerpApi adapter may still be used by an explicitly configured non-production
run with its own credential plumbing.

Database credentials stay in the separate
`private-apps/analytics-postgres-ingest` Secret and are injected as environment
variables; they are not copied into the provider Secret or ConfigMap.

## Image identity

Production orchestration should pin an immutable digest:

```text
registry.example/flight-price-tracker@sha256:...
```

Do not let the Docker path run one mutable `latest` image while Kubernetes runs another.

"""Build a flight-price collection task for Docker or Kubernetes."""

from __future__ import annotations

from dataclasses import dataclass
from datetime import timedelta, timezone
import os
from typing import Any, Mapping
from zoneinfo import ZoneInfo


APP_CONFIG = "/app/config/tracked_routes.yaml"
APP_OUTPUT_MOUNT = "/app/output"
APP_OUTPUT_ROOT = "/app/output/flight-price-tracker"
CONTROL_PLANE_LABEL = "node-role.kubernetes.io/control-plane"
TORONTO_TIMEZONE = ZoneInfo("America/Toronto")
DEFAULT_KILLSWITCH_IMAGE = (
    "qmcgaw/gluetun:v3.41.1@sha256:"
    "1a5bf4b4820a879cdf8d93d7ef0d2d963af56670c9ebff8981860b6804ebc8ab"
)
SUPPORTED_OPERATORS = {"docker", "kubernetes"}
SUPPORTED_PLACEMENTS = {"worker", "worker-preferred", "control-plane", "any"}


@dataclass(frozen=True)
class FlightTrackerSettings:
    operator: str
    image: str
    proxy_url: str
    proxy_ip: str
    proxy_port: int
    docker_url: str
    docker_conn_id: str
    docker_network: str
    docker_output_path: str
    docker_config_path: str
    kubernetes_conn_id: str
    kubernetes_namespace: str
    kubernetes_service_account: str
    kubernetes_placement: str
    kubernetes_output_pvc: str
    kubernetes_config_map: str
    kubernetes_postgres_secret: str
    killswitch_image: str

    @classmethod
    def from_env(
        cls, env: Mapping[str, str] | None = None
    ) -> FlightTrackerSettings:
        values = os.environ if env is None else env
        operator = values.get("FLIGHT_COLLECTION_OPERATOR", "kubernetes").lower()
        if operator not in SUPPORTED_OPERATORS:
            raise ValueError(
                "FLIGHT_COLLECTION_OPERATOR must be 'docker' or 'kubernetes'"
            )

        placement = values.get(
            "FLIGHT_KUBERNETES_PLACEMENT",
            values.get("SCRAPER_KUBERNETES_PLACEMENT", "worker-preferred"),
        ).lower()
        if placement not in SUPPORTED_PLACEMENTS:
            raise ValueError(
                "FLIGHT_KUBERNETES_PLACEMENT must be 'worker', "
                "'worker-preferred', 'control-plane', or 'any'"
            )

        proxy_port = int(values.get("FLIGHT_PROXY_PORT", "8888"))

===== FILE: README.md =====

# Flight Price Tracker

A portable, run-once flight collector with PostgreSQL raw landing. The same OCI
image runs under Docker, Compose, or Airflow's DockerOperator and
KubernetesPodOperator. Scheduling belongs to orchestration.

## Providers

The supplied production configuration uses `providers: [fast_flights]`, which
means FastFlights only. A FastFlights failure remains a failed collection unit
and never triggers an automatic SerpApi search. A valid empty search succeeds.
A PostgreSQL write failure fails the run without issuing another provider search.

The integration uses [fast-flights 3.1.0](https://pypi.org/project/fast-flights/3.1.0/)
to construct Google Flights queries and fetch HTML through its fetch integration
API. Our HTTP transport preserves the existing proxy, timeout, and retry settings.
fast-flights is an unofficial Google Flights scraper; it needs no API key.

Explicit `providers: [serpapi]` still selects SerpApi directly. Duffel remains
available with `DUFFEL_ACCESS_TOKEN`. The providers list represents independent
searches. The dormant SerpApi adapter is not part of the production FastFlights
path and is never used as fallback.

## Configuration and execution

Edit `config/tracked_routes.yaml`, copy `.env.example` to `.env`, and supply
complete `RAW_POSTGRES_*` settings (or `DATABASE_URL`). PostgreSQL is the only
supported storage mode. FastFlights requires no API key; an explicitly
configured SerpApi provider still requires its own credential.

The supplied targets cover AAA–BBB on March 29 and 31, and April 3, 2027, and CCC–AAA
on April 19, 20, and 22, 2027. They request one-way nonstop economy fares in CAD.
Past dates are skipped.

```bash
docker compose -f deploy/docker/docker-compose.yml run --rm tracker validate-config
docker compose -f deploy/docker/docker-compose.yml run --rm tracker plan
docker compose -f deploy/docker/docker-compose.yml run --rm tracker collect
```

`plan` performs no provider searches. It reports logical `request_count` and
`maximum_provider_attempts`; each planned provider search, including FastFlights,
uses one planning-budget unit. HTTP retries are separate transport attempts
governed by `REQUEST_RETRIES`.

## Raw landing

Successful payloads are stored in `raw.json_documents.payload` as PostgreSQL
`json`, retaining whitespace, key order, numeric spelling, and unknown fields:

- fast-flights: the original JSON array embedded in the Google Flights
  `ds:1` script. Only the HTML/JavaScript wrapper is removed.
- SerpApi: the original JSON response body, without normalization.
- Duffel: the existing raw JSON response body.

The SHA-256 and byte length describe the landed UTF-8 JSON, not the enclosing
HTML page. Request context, safe HTTP headers, actual provider, and fallback
provenance are stored separately in metadata. Streams are
`flight.fast_flights.search-response`, `flight.serpapi.search-response`, and
`flight.duffel.search-response`.

No normalized tables or output files are written. Route/date/cabin/passenger,
currency, nonstop, and airline constraints are passed to upstream searches.
Flight-number filtering and derived observations belong downstream; raw payloads
are never filtered. `raw_record_count` is a source itinerary count when available,
while the legacy observation counters do not represent raw flight inventory.

Run manifests live in `raw.ingestion_runs`, including the compatibility
`fallbacks` field (empty for FastFlights-only runs) and failures. A supplied deterministic `RUN_ID` permits successful runs to be skipped
on retry. Failed-run retries currently refetch their searches.

## Development

```bash
python -m pip install -e '.[dev,postgres]'
python -m pytest
```

See [data contract](docs/DATA_CONTRACT.md),
[request budgeting](docs/COST_CONTROL.md), and [deployment](docs/DEPLOYMENT.md).

from __future__ import annotations

from decimal import Decimal
import json
from typing import Any

import requests

from flight_price_tracker.collectors.base import ProviderResult
from flight_price_tracker.domain import (
    PriceObservation,
    SearchRequest,
    Segment,
    build_itinerary_signature,
    normalize_flight_number,
)
from flight_price_tracker.errors import CollectorError


class DuffelCollector:
    provider_name = "duffel"
    endpoint = "https://api.duffel.com/air/offer_requests"

    def __init__(
        self,
        access_token: str,
        session: requests.Session,
        timeout_seconds: float,
    ) -> None:
        self.access_token = access_token
        self.session = session
        self.timeout_seconds = timeout_seconds

    def collect(self, request: SearchRequest, collected_at: str) -> ProviderResult:
        body = {
            "data": {
                "slices": [
                    {
                        "origin": request.origin,
                        "destination": request.destination,
                        "departure_date": request.departure_date.isoformat(),
                    }
                ],
                "passengers": [{"type": "adult"} for _ in range(request.adults)],
                "cabin_class": request.cabin_class,
                "max_connections": 0 if request.nonstop_only else 1,
            }
        }
        headers = {
            "Accept": "application/json",
            "Content-Type": "application/json",
            "Accept-Encoding": "gzip",
            "Duffel-Version": "v2",
            "Authorization": f"Bearer {self.access_token}",
        }

        # Duffel recommends making supplier_timeout shorter than the caller's
        # HTTP timeout so completed airline responses can still be returned.
        supplier_timeout_ms = max(
            2000,
            min(60000, int(max(2.0, self.timeout_seconds - 5.0) * 1000)),
        )

        try:
            response = self.session.post(
                self.endpoint,
                params={
                    "return_offers": "true",
                    "supplier_timeout": supplier_timeout_ms,
                    "view": "offers",
                },
                headers=headers,
                json=body,
                timeout=self.timeout_seconds,
            )
        except requests.RequestException as exc:
            raise CollectorError(f"Duffel request failed: {exc}") from exc

        if response.status_code >= 400:
            raise CollectorError(
                f"Duffel returned HTTP {response.status_code}: {response.text[:500]}"
            )

        raw_body = response.content
        try:
            raw = json.loads(raw_body)
        except (json.JSONDecodeError, UnicodeDecodeError) as exc:
            raise CollectorError("Duffel returned non-JSON content") from exc
        if not isinstance(raw, dict):
            raise CollectorError("Duffel returned a non-object JSON response")

        data = raw.get("data")
        if not isinstance(data, dict):
            raise CollectorError("Duffel response does not contain an offer-request object")

        observations = self.normalize(raw, request, collected_at)
        return ProviderResult(
            provider=self.provider_name,
            request=request,
            raw=raw,
            observations=observations,
            raw_body=raw_body,
            response_status=response.status_code,
            response_headers=_safe_headers(response.headers),
        )

    @staticmethod
    def _airport_iata(value: Any) -> str:
        if isinstance(value, dict):
            return str(value.get("iata_code") or value.get("iata_city_code") or "")
        return str(value or "")

    @classmethod
    def normalize(
        cls,
        raw: dict[str, Any],
        request: SearchRequest,
        collected_at: str,
    ) -> list[PriceObservation]:
        offer_request = raw.get("data") or {}
        observations: list[PriceObservation] = []

        for offer in offer_request.get("offers") or []:
            segments: list[Segment] = []
            for slice_ in offer.get("slices") or []:
                for segment in slice_.get("segments") or []:
                    marketing = segment.get("marketing_carrier") or {}
                    operating = segment.get("operating_carrier") or {}
                    flight_number = normalize_flight_number(
                        f"{marketing.get('iata_code') or ''}"
                        f"{segment.get('marketing_carrier_flight_number') or ''}"
                    )
                    segments.append(
                        Segment(
                            origin=cls._airport_iata(segment.get("origin")),
                            destination=cls._airport_iata(segment.get("destination")),
                            departure_time_local=segment.get("departing_at"),
                            arrival_time_local=segment.get("arriving_at"),
                            duration_minutes=_iso8601_duration_minutes(
                                segment.get("duration")
                            ),
                            marketing_carrier_code=marketing.get("iata_code"),
                            marketing_carrier_name=marketing.get("name"),
                            operating_carrier_code=operating.get("iata_code"),
                            operating_carrier_name=operating.get("name"),
                            flight_number=flight_number,
                            aircraft=(segment.get("aircraft") or {}).get("name"),
                        )
                    )

            if not segments or offer.get("total_amount") is None:

            observation = PriceObservation(

def _iso8601_duration_minutes(value: str | None) -> int | None:
    """Parse the PT#H#M subset used for flight segment durations."""
    if not value or not value.startswith("PT"):
        return None
    body = value[2:]
    hours = 0
    minutes = 0
    if "H" in body:
        hour_text, body = body.split("H", 1)
        hours = int(hour_text or 0)
    if "M" in body:
        minute_text = body.split("M", 1)[0]
        minutes = int(minute_text or 0)
    return hours * 60 + minutes


def _safe_headers(headers: Any) -> dict[str, str]:
    allowed = {
        "cache-control",
        "content-length",
        "content-type",
        "date",
        "etag",
        "last-modified",
        "request-id",
        "x-request-id",
    }
    return {
        key.lower(): value
        for key, value in headers.items()
        if key.lower() in allowed
    }

class FastFlightsCollector:
    provider_name = "fast_flights"

    def __init__(self, session: requests.Session, timeout_seconds: float):
        self.session = session
        self.timeout_seconds = timeout_seconds

    def collect(self, request: SearchRequest, collected_at: str) -> ProviderResult:
        query = create_query(
            flights=[FlightQuery(
                date=request.departure_date.isoformat(),
                from_airport=request.origin,
                to_airport=request.destination,
                max_stops=0 if request.nonstop_only else None,
                airlines=list(request.include_airlines) or None,
            )],
            seat=request.cabin_class.replace("_", "-"),
            trip="one-way",
            passengers=Passengers(adults=request.adults),
            language=request.language,
            currency=request.currency,
        )
        transport = _Transport(self.session, self.timeout_seconds, request.country)
        try:
            html = fetch_flights_html(query, fetch_integration=transport)
            script = LexborHTMLParser(html).css_first(r"script.ds\:1")
            if script is None:
                raise ValueError("missing flight data (possibly a consent or challenge page)")
            # Same data boundary as fast-flights 3.1.0's parser. Keep the JSON
            # substring itself, including unknown fields and numeric spelling.
            payload_text = script.text().split("data:", 1)[1].rsplit(",", 1)[0]
            raw = json.loads(payload_text, parse_constant=_reject_constant)
            records = raw[3][0]
            if records is not None and not isinstance(records, list):
                raise ValueError("unexpected flight list")
            if not isinstance(raw[7][1], list):
                raise ValueError("missing flight search metadata")
        except Exception as exc:
            # Do not copy request URLs, proxy credentials, or page bodies into
            # run metadata. The service records the safe exception category.
            raise CollectorError(
                f"fast-flights fetch or payload validation failed ({type(exc).__name__})"
            ) from exc

        response = transport.response
        return ProviderResult(
            provider=self.provider_name,
            request=request,
            raw=raw,
            observations=[],
            raw_body=payload_text.encode("utf-8"),
            response_status=response.status_code,
            response_headers=_safe_headers(response.headers),
            raw_record_count=len(records or []),
        )

class SerpApiCollector:
    provider_name = "serpapi"
    endpoint = "https://serpapi.com/search"

    def __init__(
        self,
        api_key: str,
        session: requests.Session,
        timeout_seconds: float,
        *,
        raw_only: bool = False,
    ) -> None:
        self.api_key = api_key
        self.session = session
        self.timeout_seconds = timeout_seconds
        self.raw_only = raw_only

    def collect(self, request: SearchRequest, collected_at: str) -> ProviderResult:
        params: dict[str, Any] = {
            "engine": "google_flights",
            "api_key": self.api_key,
            "departure_id": request.origin,
            "arrival_id": request.destination,
            "outbound_date": request.departure_date.isoformat(),
            "type": 2,
            "travel_class": TRAVEL_CLASS[request.cabin_class],
            "currency": request.currency,
            "adults": request.adults,
            "gl": request.country,
            "hl": request.language,
            "deep_search": str(request.serpapi_deep_search).lower(),
        }
        if request.nonstop_only:
            params["stops"] = 1
        if request.include_airlines:
            params["include_airlines"] = ",".join(request.include_airlines)

        try:
            response = self.session.get(
                self.endpoint,
                params=params,
                timeout=self.timeout_seconds,
            )
        except requests.RequestException as exc:
            raise CollectorError(f"SerpApi request failed: {exc}") from exc

        if response.status_code >= 400:
            raise CollectorError(
                f"SerpApi returned HTTP {response.status_code}: {response.text[:500]}"
            )

        raw_body = response.content
        try:
            raw = json.loads(raw_body)
        except (json.JSONDecodeError, UnicodeDecodeError) as exc:
            raise CollectorError("SerpApi returned non-JSON content") from exc
        if not isinstance(raw, dict):
            raise CollectorError("SerpApi returned a non-object JSON response")
        response_headers = _safe_headers(response.headers)

        if raw.get("error"):
            error = str(raw["error"])
            # Google Flights reports a valid empty search as an API-level
            # error. For sparse nonstop routes this is expected data, not a
            # failed collection unit. Preserve the response and checkpoint an
            # empty observation list so retries do not spend another credit.
            if "hasn't returned any results" in error.lower():
                return ProviderResult(
                    provider=self.provider_name,
                    request=request,
                    raw=raw,
                    observations=[],
                    raw_body=raw_body,
                    response_status=response.status_code,
                    response_headers=response_headers,
                )
            raise CollectorError(f"SerpApi error: {error}")

        observations = [] if self.raw_only else self.normalize(raw, request, collected_at)
        return ProviderResult(
            provider=self.provider_name,
            request=request,
            raw=raw,
            observations=observations,
            raw_body=raw_body,
            response_status=response.status_code,
            response_headers=response_headers,
            raw_record_count=sum(
                len(raw.get(bucket) or [])
                for bucket in ("best_flights", "other_flights")
                if isinstance(raw.get(bucket) or [], list)
            ),
        )

    @classmethod
    def normalize(
        cls,
        raw: dict[str, Any],
        request: SearchRequest,
        collected_at: str,
    ) -> list[PriceObservation]:
        observations: list[PriceObservation] = []

        for bucket in ("best_flights", "other_flights"):
            for itinerary in raw.get(bucket) or []:
                flights = itinerary.get("flights") or []
                if not flights or itinerary.get("price") is None:
                    continue

                segments: list[Segment] = []
                for flight in flights:
                    departure = flight.get("departure_airport") or {}
                    arrival = flight.get("arrival_airport") or {}
                    flight_number = normalize_flight_number(flight.get("flight_number"))
                    segments.append(
                        Segment(
                            origin=str(departure.get("id") or ""),
                            destination=str(arrival.get("id") or ""),
                            departure_time_local=departure.get("time"),
                            arrival_time_local=arrival.get("time"),
                            duration_minutes=flight.get("duration"),
                            marketing_carrier_code=carrier_code_from_flight_number(
                                flight_number
                            ),
                            marketing_carrier_name=flight.get("airline"),
                            operating_carrier_code=None,
                            operating_carrier_name=None,
                            flight_number=flight_number,
                            aircraft=flight.get("airplane"),
                        )
                    )

                currency = (
                    (raw.get("search_parameters") or {}).get("currency")
                    or request.currency
                )
                price = Decimal(str(itinerary["price"]))

                observation = PriceObservation(
                    provider=cls.provider_name,
                    collected_at=collected_at,
                    target_id=request.target_id,
                    search_origin=request.origin,
                    search_destination=request.destination,
                    search_departure_date=request.departure_date.isoformat(),
                    cabin_class=request.cabin_class,
                    currency=str(currency).upper(),
                    total_amount=price,
                    base_amount=None,
                    tax_amount=None,
                    provider_offer_id=itinerary.get("booking_token"),
                    itinerary_signature=build_itinerary_signature(segments),
                    total_duration_minutes=itinerary.get("total_duration"),
                    stops=max(0, len(segments) - 1),
                    fare_brand=None,
                    segments=segments,
                    source_bucket=bucket,
                    provider_metadata={
                        "type": itinerary.get("type"),
                        "extensions": itinerary.get("extensions") or [],
                        "carbon_emissions": itinerary.get("carbon_emissions"),
                        "price_insights": raw.get("price_insights"),
                    },
                ).finalize()
                observations.append(observation)

        return observations

def _secret_value(value_name: str, file_name: str) -> str | None:

@dataclass(frozen=True)
class DateSpec:
    mode: str
    start_date: date | None = None
    end_date: date | None = None
    start_days_ahead: int | None = None
    end_days_ahead: int | None = None
    step_days: int = 1
    values: tuple[date, ...] = ()

    def resolve(self, anchor: date) -> list[date]:
        if self.mode == "explicit":
            return sorted(set(self.values))
        if self.mode == "calendar_range":
            assert self.start_date is not None
            assert self.end_date is not None
            return [
                self.start_date + timedelta(days=offset)
                for offset in range(
                    0,
                    (self.end_date - self.start_date).days + 1,
                    self.step_days,
                )
            ]
        assert self.start_days_ahead is not None
        assert self.end_days_ahead is not None
        return [
            anchor + timedelta(days=offset)
            for offset in range(
                self.start_days_ahead,
                self.end_days_ahead + 1,
                self.step_days,
            )
        ]

@dataclass(frozen=True)
class TrackingConfig:
    version: int
    targets: tuple[TrackingTarget, ...] = field(default_factory=tuple)

    @property
    def enabled_targets(self) -> tuple[TrackingTarget, ...]:
        return tuple(target for target in self.targets if target.enabled)

    def build_search_requests(self, anchor: date) -> list[tuple[str, SearchRequest]]:
        planned: list[tuple[str, SearchRequest]] = []
        for target in self.enabled_targets:
            for departure_date in target.dates.resolve(anchor):
                if target.skip_past_dates and departure_date < anchor:
                    continue
                request = SearchRequest(
                    target_id=target.id,
                    origin=target.origin,
                    destination=target.destination,
                    departure_date=departure_date,
                    cabin_class=target.cabin_class,
                    currency=target.currency,
                    adults=target.adults,
                    nonstop_only=target.nonstop_only,
                    country=target.country,
                    language=target.language,
                    include_airlines=target.include_airlines,
                    flight_numbers=target.flight_numbers,
                    serpapi_deep_search=target.serpapi_deep_search,
                )
                for provider in target.providers:
                    planned.append((provider, request))
        return planned

    def enforce_request_budget(self, anchor: date, limit: int) -> int:
        count = len(self.build_search_requests(anchor))
        if count > limit:
            raise RequestBudgetExceeded(
                f"Planned {count} provider requests, exceeding MAX_REQUESTS_PER_RUN={limit}. "
                "Reduce enabled targets/date density/providers or raise the limit deliberately."
            )
        return count

def _date_spec(raw: dict[str, Any]) -> DateSpec:
    mode = str(raw.get("mode", "")).strip().lower()
    if mode == "explicit":
        values = raw.get("values") or []
        if not values:
            raise ConfigurationError("Explicit dates require at least one value")
        try:
            parsed = tuple(date.fromisoformat(str(value)) for value in values)
        except ValueError as exc:
            raise ConfigurationError(f"Invalid explicit date: {exc}") from exc
        return DateSpec(mode="explicit", values=parsed)

    if mode == "calendar_range":
        try:
            start_date = date.fromisoformat(str(raw["start_date"]))
            end_date = date.fromisoformat(str(raw["end_date"]))
            step = int(raw.get("step_days", 1))
        except (KeyError, TypeError, ValueError) as exc:
            raise ConfigurationError(
                "Calendar ranges require ISO start_date/end_date and an integer step_days"
            ) from exc
        if end_date < start_date or step < 1:
            raise ConfigurationError(
                "Calendar ranges require start_date <= end_date and step_days >= 1"
            )
        return DateSpec(
            mode="calendar_range",
            start_date=start_date,
            end_date=end_date,
            step_days=step,
        )

    if mode == "rolling":
        try:
            start = int(raw["start_days_ahead"])
            end = int(raw["end_days_ahead"])
            step = int(raw.get("step_days", 1))
        except (KeyError, TypeError, ValueError) as exc:
            raise ConfigurationError(
                "Rolling dates require integer start_days_ahead/end_days_ahead/step_days"
            ) from exc
        if start < 0 or end < start or step < 1:
            raise ConfigurationError(
                "Rolling dates require 0 <= start_days_ahead <= end_days_ahead and step_days >= 1"
            )
        return DateSpec(
            mode="rolling",
            start_days_ahead=start,
            end_days_ahead=end,
            step_days=step,
        )

    raise ConfigurationError(
        "dates.mode must be calendar_range, explicit, or rolling"
    )


def load_tracking_config(path: Path) -> TrackingConfig:
    if not path.exists():
        raise ConfigurationError(f"Tracking config does not exist: {path}")

    raw = yaml.safe_load(path.read_text()) or {}
    if raw.get("version") != 1:
        raise ConfigurationError("Only tracking config version 1 is supported")

    defaults = raw.get("defaults") or {}
    targets_raw = raw.get("targets") or []
    if not isinstance(targets_raw, list):
        raise ConfigurationError("targets must be a list")

    targets: list[TrackingTarget] = []
    seen_ids: set[str] = set()

    for item in targets_raw:
        merged = {**defaults, **(item or {})}
        target_id = str(merged.get("id", "")).strip()
        if not re.fullmatch(r"[a-z0-9][a-z0-9_-]{1,62}", target_id):
            raise ConfigurationError(
                f"Invalid target id {target_id!r}; use lowercase letters, numbers, _ or -"
            )
        if target_id in seen_ids:
            raise ConfigurationError(f"Duplicate target id: {target_id}")
        seen_ids.add(target_id)

        providers = tuple(
            dict.fromkeys(str(p).strip().lower() for p in merged.get("providers", []))
        )
        if not providers or not set(providers).issubset(ALLOWED_PROVIDERS):
            raise ConfigurationError(
                f"{target_id}: providers must be a non-empty subset of {sorted(ALLOWED_PROVIDERS)}"
            )

        cabin_class = str(merged.get("cabin_class", "economy")).strip().lower()
        if cabin_class not in ALLOWED_CABINS:
            raise ConfigurationError(
                f"{target_id}: cabin_class must be one of {sorted(ALLOWED_CABINS)}"
            )

        currency = str(merged.get("currency", "CAD")).strip().upper()
        if not re.fullmatch(r"[A-Z]{3}", currency):
            raise ConfigurationError(f"{target_id}: currency must be a 3-letter code")

        adults = int(merged.get("adults", 1))
        if adults < 1 or adults > 9:
            raise ConfigurationError(f"{target_id}: adults must be between 1 and 9")

        flight_numbers = tuple(
            dict.fromkeys(
                value
                for raw_value in merged.get("flight_numbers", [])
                if (value := normalize_flight_number(str(raw_value)))
            )
        )

        targets.append(
            TrackingTarget(
                id=target_id,
                enabled=_config_bool(
                    merged.get("enabled"), f"{target_id}.enabled", True
                ),
                origin=_iata(merged.get("origin"), f"{target_id}.origin"),
                destination=_iata(merged.get("destination"), f"{target_id}.destination"),
                providers=providers,
                cabin_class=cabin_class,
                currency=currency,
                adults=adults,
                nonstop_only=_config_bool(
                    merged.get("nonstop_only"),
                    f"{target_id}.nonstop_only",
                    True,
                ),
                country=str(merged.get("country", "ca")).strip().lower(),
                language=str(merged.get("language", "en")).strip().lower(),
                serpapi_deep_search=_config_bool(
                    merged.get("serpapi_deep_search"),
                    f"{target_id}.serpapi_deep_search",
                    False,
                ),
                skip_past_dates=_config_bool(
                    merged.get("skip_past_dates"),
                    f"{target_id}.skip_past_dates",
                    True,
                ),
                include_airlines=_airline_codes(merged.get("include_airlines")),
                flight_numbers=flight_numbers,
                dates=_date_spec(merged.get("dates") or {}),
            )
        )

    if not targets:
        raise ConfigurationError("At least one target must be configured")

    return TrackingConfig(version=1, targets=tuple(targets))


def validate_provider_credentials(config: TrackingConfig, settings: Settings) -> None:
    providers = {
        provider
        for target in config.enabled_targets
        for provider in target.providers
    }
    if "serpapi" in providers and not settings.serpapi_api_key:
        raise ConfigurationError(
            "SERPAPI_API_KEY is required because an enabled target uses serpapi"
        )
    if "duffel" in providers and not settings.duffel_access_token:
        raise ConfigurationError(
            "DUFFEL_ACCESS_TOKEN is required because an enabled target uses duffel"
        )

def canonical_json_bytes(value: Any) -> bytes:
    return json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(',', ':')).encode('utf-8')

def fingerprint(value: Any) -> str:
    return sha256(canonical_json_bytes(value)).hexdigest()

def request_definition(provider: str, request: SearchRequest) -> dict[str, Any]:
    d = asdict(request)
    d['departure_date'] = request.departure_date.isoformat()
    d['include_airlines'] = list(request.include_airlines)
    d['flight_numbers'] = list(request.flight_numbers)
    return {'provider': provider, **d}

def request_key(definition: dict[str, Any]) -> str:
    return fingerprint(definition)

def canonical_plan(planned):
    rows=[request_definition(p,r) for p,r in planned]
    rows.sort(key=lambda x: canonical_json_bytes(x))
    return rows

def normalize_flight_number(value: str | None) -> str | None:
    if not value:

def carrier_code_from_flight_number(value: str | None) -> str | None:
    normalized = normalize_flight_number(value)

    match = re.match(r"^([A-Z0-9]{2})(?=\d)", normalized)

class PriceObservation:
    provider: str
    collected_at: str
    target_id: str
    search_origin: str
    search_destination: str
    search_departure_date: str
    cabin_class: str
    currency: str

    base_amount: Decimal | None
    tax_amount: Decimal | None

    segments: list[Segment]
    source_bucket: str | None = None
    provider_metadata: dict[str, Any] = field(default_factory=dict)
    record_key: str = ""

    def finalize(self) -> "PriceObservation":
        if not self.record_key:
            identity = {
                "provider": self.provider,
                "target_id": self.target_id,
                "search_departure_date": self.search_departure_date,
                "itinerary_signature": self.itinerary_signature,
                "cabin_class": self.cabin_class,
                "currency": self.currency,
                "total_amount": str(self.total_amount),
                "fare_brand": self.fare_brand,
                "provider_offer_id": self.provider_offer_id,
            }
            self.record_key = sha256(
                json.dumps(identity, sort_keys=True, separators=(",", ":")).encode()
            ).hexdigest()
        return self

    @classmethod
    def from_dict(cls, payload: dict[str, Any]) -> "PriceObservation":
        data = dict(payload)
        data["total_amount"] = Decimal(data["total_amount"])
        data["base_amount"] = None if data.get("base_amount") is None else Decimal(data["base_amount"])
        data["tax_amount"] = None if data.get("tax_amount") is None else Decimal(data["tax_amount"])
        data["segments"] = [Segment(**segment) for segment in data.get("segments", [])]
        return cls(**data)

    def to_dict(self) -> dict[str, Any]:
        payload = asdict(self)
        payload["total_amount"] = str(self.total_amount)
        payload["base_amount"] = None if self.base_amount is None else str(self.base_amount)
        payload["tax_amount"] = None if self.tax_amount is None else str(self.tax_amount)
        return payload


def build_itinerary_signature(segments: list[Segment]) -> str:
    parts = []
    for segment in segments:
        parts.append(
            "|".join(
                [
                    segment.origin,
                    segment.destination,
                    normalize_flight_number(segment.flight_number) or "",
                    segment.departure_time_local or "",
                    segment.arrival_time_local or "",
                ]
            )
        )
    return sha256("||".join(parts).encode()).hexdigest()

from __future__ import annotations

from flight_price_tracker.domain import PriceObservation, SearchRequest, normalize_flight_number


def observation_matches_request(
    observation: PriceObservation,
    request: SearchRequest,
) -> bool:
    if (
        observation.target_id != request.target_id
        or observation.search_origin != request.origin
        or observation.search_destination != request.destination
        or observation.search_departure_date != request.departure_date.isoformat()
        or observation.cabin_class != request.cabin_class
    ):
        return False

    if not observation.segments:
        return False
    if (
        observation.segments[0].origin != request.origin
        or observation.segments[-1].destination != request.destination
    ):
        return False

    if request.nonstop_only and observation.stops != 0:
        return False
    if request.nonstop_only and len(observation.segments) != 1:
        return False

    if request.include_airlines:
        allowed = set(request.include_airlines)
        observed_codes = {
            segment.marketing_carrier_code
            for segment in observation.segments
            if segment.marketing_carrier_code
        }
        if not observed_codes or not observed_codes.issubset(allowed):
            return False

    if request.flight_numbers:
        allowed_numbers = {
            normalize_flight_number(value) for value in request.flight_numbers
        }
        observed_numbers = {
            normalize_flight_number(segment.flight_number)
            for segment in observation.segments
            if segment.flight_number
        }
        if not observed_numbers.intersection(allowed_numbers):
            return False

    return True

from __future__ import annotations

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry


def build_session(retries: int) -> requests.Session:
    retry = Retry(
        total=retries,
        connect=retries,
        read=retries,
        status=retries,
        backoff_factor=1.0,
        status_forcelist=(429, 500, 502, 503, 504),
        # Retrying Duffel's POST automatically could create duplicate offer
        # requests after an ambiguous read timeout. SerpApi GETs are safe to
        # retry; Duffel failures are checkpointed and retried by Airflow.
        allowed_methods=frozenset({"GET"}),
        respect_retry_after_header=True,
        raise_on_status=False,
    )
    adapter = HTTPAdapter(max_retries=retry)
    session = requests.Session()
    session.mount("https://", adapter)
    session.mount("http://", adapter)
    # requests automatically honors HTTP_PROXY / HTTPS_PROXY / NO_PROXY.
    return session

class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        payload = {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
        }
        for key in ("run_id", "target_id", "provider", "departure_date"):
            value = getattr(record, key, None)
            if value is not None:
                payload[key] = value
        if record.exc_info:
            payload["exception"] = self.formatException(record.exc_info)
        return json.dumps(payload, ensure_ascii=False)

    handler = logging.StreamHandler(sys.stdout)
    handler.setFormatter(JsonFormatter())

    root = logging.getLogger()
    root.handlers.clear()
    root.addHandler(handler)
    root.setLevel(level.upper())

from __future__ import annotations
from dataclasses import dataclass
from datetime import date, datetime, timezone
import os


def parse_utc(value: str) -> datetime:
    parsed = datetime.fromisoformat(value.replace('Z', '+00:00'))
    if parsed.tzinfo is None:
        parsed = parsed.replace(tzinfo=timezone.utc)
    return parsed.astimezone(timezone.utc)


def iso_utc(value: datetime) -> str:
    return value.astimezone(timezone.utc).isoformat().replace('+00:00', 'Z')

@dataclass(frozen=True)
class RunContext:
    run_id: str
    logical_at: datetime
    anchor_date: date
    attempt_started_at: datetime

    @classmethod
    def resolve(cls, *, cli_run_id=None, cli_logical_at=None, cli_anchor_date=None, environ=None, now=None):
        env = os.environ if environ is None else environ
        initial = (now or datetime.now(timezone.utc)).astimezone(timezone.utc)
        logical = parse_utc(cli_logical_at or env.get('LOGICAL_AT')) if (cli_logical_at or env.get('LOGICAL_AT')) else initial
        anchor = date.fromisoformat(cli_anchor_date or env.get('ANCHOR_DATE')) if (cli_anchor_date or env.get('ANCHOR_DATE')) else logical.date()
        run_id = cli_run_id or env.get('RUN_ID') or logical.strftime('%Y%m%dT%H%M%S.%fZ')
        return cls(run_id=run_id, logical_at=logical, anchor_date=anchor, attempt_started_at=initial)

    def stable_dict(self):
        return {'run_id': self.run_id, 'logical_at': iso_utc(self.logical_at), 'anchor_date': self.anchor_date.isoformat()}

def _land_checkpoint(
    sink: RawLandingSink,
    context: RunContext,
    key: str,
    request_definition: dict[str, Any],
    response_body: bytes,
    capture: dict[str, Any],
) -> None:
    provider = str(capture.get("provider", request_definition["provider"]))
    source_record_id = "/".join(
        (
            provider,
            str(request_definition["origin"]),
            str(request_definition["destination"]),
            str(request_definition["departure_date"]),
            key,
        )
    )
    sink.write_document(
        RawDocument(
            run_id=context.run_id,
            document_key=f"request/{key}",
            stream=f"flight.{provider}.search-response",
            source_record_id=source_record_id,
            observed_at=iso_utc(context.logical_at),
            fetched_at=capture.get("provider_fetched_at"),
            payload_text=response_body.decode("utf-8"),
            payload_sha256=sha256(response_body).hexdigest(),
            payload_bytes=len(response_body),
            metadata={
                "request_definition": request_definition,
                "request_key": key,
                "target_id": request_definition["target_id"],
                "provider": provider,
                "fallback_from": capture.get("fallback_from"),
                "primary_error_type": capture.get("primary_error_type"),
                "raw_record_count": capture.get("raw_record_count"),
                "origin": request_definition["origin"],
                "destination": request_definition["destination"],
                "departure_date": request_definition["departure_date"],
                "http_status": capture.get("http_status"),
                "response_headers": capture.get("response_headers", {}),
                "provider_observation_count": capture.get(
                    "provider_observation_count"
                ),
                "accepted_observation_count": capture.get(
                    "accepted_observation_count"
                ),
            },
        )
    )


def collect(
    config: TrackingConfig, settings: Settings, context: RunContext
) -> dict[str, Any]:
    plan = resolved_plan(config, settings, context.anchor_date)
    config_sha256 = sha256(settings.config_path.read_bytes()).hexdigest()
    definition = {
        "schema_version": 2,
        **context.stable_dict(),
        "application_version": __version__,
        "tracking_config_sha256": config_sha256,
        "resolved_plan_sha256": fingerprint(plan),
        "requests": [
            {**row, "request_key": request_key(row)} for row in plan
        ],
    }
    validate_provider_credentials(config, settings)
    definition_sha256 = fingerprint(definition)
    collectors = make_collectors(settings)
    raw_environment = None
    if settings.database_url:
        raw_environment = dict(os.environ)
        raw_environment["DATABASE_URL"] = settings.database_url
    raw_sink = RawLandingSink.from_env(
        "flight-price-tracker", __version__, raw_environment
    )
    if raw_sink is None:
        raise RuntimeError("raw PostgreSQL landing is required")
    raw_sink.ensure_schema()
    if raw_sink.run_status(context.run_id) == "succeeded":
        if settings.skip_successful_run:
            return {
                "run_id": context.run_id,
                "status": "skipped_already_successful",
                "run_definition_sha256": definition_sha256,
            }
        raise ValueError("The run is already complete and immutable")
    raw_sink.start_run(context.run_id, iso_utc(context.attempt_started_at))
    observations = []
    failures = []
    executed = 0
    provider_attempts = 0
    fallbacks = []

    for item in definition["requests"]:
        key = item["request_key"]
        request_definition = {
            name: value for name, value in item.items() if name != "request_key"
        }
        provider, request = _search_request(request_definition)
        fetched_at = iso_utc(utc_now())
        try:
            provider_attempts += 1
            result = collectors[provider].collect(request, fetched_at)
            accepted = [
                observation
                for observation in result.observations
                if observation_matches_request(observation, request)
            ]
            response_body = result.raw_body
            if response_body is None:
                import json
                response_body = json.dumps(result.raw, separators=(",", ":")).encode()
            capture = {
                "provider": result.provider,
                "raw_record_count": result.raw_record_count,
                "provider_fetched_at": fetched_at,
                "provider_observation_count": len(result.observations),
                "accepted_observation_count": len(accepted),
                "http_status": result.response_status,
                "response_headers": result.response_headers,
            }
        except Exception as exc:  # preserve successful checkpoints for retry
            logger.exception("Collection request %s failed", key)
            failures.append(
                {
                    "request_key": key,
                    "provider": provider,
                    "error_type": type(exc).__name__,
                    "error": str(exc),
                }
            )
            continue

        try:
            _land_checkpoint(
                raw_sink, context, key, request_definition, response_body, capture
            )
        except BaseException as error:
            raw_sink.fail_run(context.run_id, error)
            raise
        observations.extend(accepted)
        executed += 1

    try:
        if not failures:
            status = "success"
        elif executed:
            status = "partial_failure"
        else:
            status = "failed"

        manifest = {
            "schema_version": 3,
            "run_id": context.run_id,
            "logical_at": iso_utc(context.logical_at),
            "anchor_date": context.anchor_date.isoformat(),
            "attempt_started_at": iso_utc(context.attempt_started_at),
            "run_definition_sha256": definition_sha256,
            "status": status,
            "planned_requests": len(plan),
            "completed_requests": len(plan) - len(failures),
            "reused_requests": 0,
            "executed_requests": executed,
            "provider_attempts": provider_attempts,
            "fallbacks": fallbacks,
            "failed_requests": len(failures),
            "observation_count": len(observations),
            "storage_mode": "postgres",
            "failures": failures,
            "files": [],
        }

        raw_status = {
            "success": "succeeded", "partial_failure": "partial", "failed": "failed",
        }[status]
        raw_sink.complete_run(
            context.run_id, raw_status, manifest, len(plan) - len(failures)
        )
        should_fail = bool(failures) and (
            settings.fail_on_partial or not executed
        )
        return {
            **manifest,
            "exit_success": not should_fail,
        }
    except BaseException as error:
        raw_sink.fail_run(context.run_id, error)
        raise

"""Append-only raw JSON landing in analytics PostgreSQL."""

from __future__ import annotations

import os
from dataclasses import dataclass
from importlib.resources import files
from typing import Any, Mapping


class RawLandingError(RuntimeError):
    """Raw landing configuration, connectivity, or idempotency failure."""


@dataclass(frozen=True)
class RawDocument:
    run_id: str
    document_key: str
    stream: str
    source_record_id: str
    observed_at: str
    fetched_at: str | None
    payload_text: str
    payload_sha256: str
    payload_bytes: int
    metadata: Mapping[str, Any]


@dataclass(frozen=True)
class _ConnectionSettings:
    host: str | None = None
    port: int = 5432
    database: str | None = None
    user: str | None = None
    password: str | None = None
    database_url: str | None = None


class RawLandingSink:
    def __init__(
        self,
        producer: str,
        application_version: str,
        settings: _ConnectionSettings,
    ) -> None:
        self.producer = producer
        self.application_version = application_version
        self.settings = settings

    @classmethod
    def from_env(
        cls,
        producer: str,
        application_version: str,
        environ: Mapping[str, str] | None = None,
    ) -> RawLandingSink | None:
        values = os.environ if environ is None else environ
        required = _boolean(values.get("RAW_POSTGRES_REQUIRED", "false"))
        database_url = values.get("DATABASE_URL", "").strip()
        names = (
            "RAW_POSTGRES_HOST",
            "RAW_POSTGRES_DATABASE",
            "RAW_POSTGRES_USER",
            "RAW_POSTGRES_PASSWORD",
        )
        present = {name: values.get(name, "").strip() for name in names}
        if not any(present.values()) and database_url:
            return cls(
                producer,
                application_version,
                _ConnectionSettings(database_url=database_url),
            )
        if not any(present.values()) and not required:
            return None
        missing = [name for name, value in present.items() if not value]
        if missing:
            raise RawLandingError(
                "missing raw PostgreSQL settings: " + ", ".join(missing)
            )
        try:
            port = int(values.get("RAW_POSTGRES_PORT", "5432"))
        except ValueError as error:
            raise RawLandingError("RAW_POSTGRES_PORT must be an integer") from error
        if not 1 <= port <= 65535:
            raise RawLandingError("RAW_POSTGRES_PORT must be between 1 and 65535")
        return cls(
            producer,
            application_version,
            _ConnectionSettings(
                host=present["RAW_POSTGRES_HOST"],
                port=port,
                database=present["RAW_POSTGRES_DATABASE"],
                user=present["RAW_POSTGRES_USER"],
                password=present["RAW_POSTGRES_PASSWORD"],
            ),
        )

    def _connect(self):
        from psycopg import connect

        if self.settings.database_url:
            return connect(
                self.settings.database_url,
                connect_timeout=10,
                application_name=self.producer,
            )
        return connect(
            host=self.settings.host,
            port=self.settings.port,
            dbname=self.settings.database,
            user=self.settings.user,
            password=self.settings.password,
            connect_timeout=10,
            application_name=self.producer,
        )

    def ensure_schema(self) -> None:
        schema = files(__package__).joinpath("schema.sql").read_text(encoding="utf-8")
        with self._connect() as connection:
            connection.execute(schema)

    def run_status(self, run_id: str) -> str | None:
        with self._connect() as connection:
            row = connection.execute(
                "SELECT status FROM raw.ingestion_runs WHERE producer = %s AND run_id = %s",
                (self.producer, run_id),
            ).fetchone()
        return None if row is None else str(row[0])

    def start_run(self, run_id: str, started_at: str) -> None:
        statement = """
        INSERT INTO raw.ingestion_runs (
            producer, run_id, application_version, status, started_at
        ) VALUES (%s, %s, %s, 'running', %s)
        ON CONFLICT (producer, run_id) DO UPDATE SET
            application_version = EXCLUDED.application_version,
            status = 'running', completed_at = NULL,
            error = NULL, updated_at = NOW()
        WHERE raw.ingestion_runs.status <> 'succeeded'
        RETURNING status
        """
        with self._connect() as connection:
            row = connection.execute(
                statement,
                (self.producer, run_id, self.application_version, started_at),
            ).fetchone()
        if row is None:
            raise RawLandingError(f"raw PostgreSQL run {run_id!r} is already succeeded")

    def write_document(self, document: RawDocument) -> None:
        from psycopg.types.json import Jsonb

        statement = """
        INSERT INTO raw.json_documents (
            producer, run_id, document_key, stream, source_record_id,
            observed_at, fetched_at, application_version, payload,
            payload_sha256, payload_bytes, metadata
        ) VALUES (%s, %s, %s, %s, %s, %s, %s, %s, %s::json, %s, %s, %s)
        ON CONFLICT (producer, run_id, document_key) DO NOTHING
        RETURNING payload_sha256, payload_bytes
        """
        identity = (self.producer, document.run_id, document.document_key)
        with self._connect() as connection:
            row = connection.execute(
                statement,
                (
                    *identity,
                    document.stream,
                    document.source_record_id,
                    document.observed_at,
                    document.fetched_at,
                    self.application_version,
                    document.payload_text,
                    document.payload_sha256,
                    document.payload_bytes,
                    Jsonb(dict(document.metadata)),
                ),
            ).fetchone()
            if row is None:
                row = connection.execute(
                    """
                    SELECT payload_sha256, payload_bytes
                    FROM raw.json_documents
                    WHERE producer = %s AND run_id = %s AND document_key = %s
                    """,
                    identity,
                ).fetchone()
                if row != (document.payload_sha256, document.payload_bytes):
                    raise RawLandingError(
                        f"raw document conflict for run={document.run_id!r} "
                        f"key={document.document_key!r}"
                    )

    def complete_run(
        self,
        run_id: str,
        status: str,
        manifest: Mapping[str, Any],
        document_count: int,
    ) -> None:
        from psycopg.types.json import Jsonb

        if status not in {"succeeded", "partial", "failed"}:
            raise ValueError(f"invalid raw landing run status: {status}")
        with self._connect() as connection:
            row = connection.execute(
                """
                UPDATE raw.ingestion_runs
                SET status = %s, completed_at = NOW(), document_count = %s,
                    manifest = %s, error = NULL, updated_at = NOW()
                WHERE producer = %s AND run_id = %s
                RETURNING status
                """,
                (status, document_count, Jsonb(dict(manifest)), self.producer, run_id),
            ).fetchone()
        if row is None:
            raise RawLandingError(f"raw PostgreSQL run {run_id!r} was not started")

    def fail_run(self, run_id: str, error: BaseException) -> None:
        try:
            from psycopg.types.json import Jsonb

            with self._connect() as connection:
                connection.execute(
                    """
                    UPDATE raw.ingestion_runs
                    SET status = 'failed', completed_at = NOW(),
                        error = %s, updated_at = NOW()
                    WHERE producer = %s AND run_id = %s
                    """,
                    (
                        Jsonb({"error_type": type(error).__name__, "error": str(error)[:2000]}),
                        self.producer,
                        run_id,
                    ),
                )
        except Exception:
            return


def _boolean(value: str) -> bool:
    normalized = value.strip().lower()
    if normalized in {"1", "true", "yes", "on"}:
        return True
    if normalized in {"0", "false", "no", "off"}:
        return False
    raise RawLandingError("RAW_POSTGRES_REQUIRED must be a boolean")

from dataclasses import replace

from flight_price_tracker.domain import SearchRequest

PAYLOAD = '[null,null,null,[[{"unknown": 1.00, "label": "航班"}]],null,null,null,[null,[[],[]]]]'


def search():
    return SearchRequest(
        target_id="yyz-pek", origin="YYZ", destination="PEK",
        departure_date=date(2026, 11, 12), cabin_class="premium_economy",
        currency="CAD", adults=2, nonstop_only=True, country="ca", language="en",
        include_airlines=("AC",),
    )


def session_for(html, status=200):
    response = requests.Response()
    response.status_code = status
    response._content = html.encode()
    response.headers = {"Content-Type": "text/html", "Set-Cookie": "secret"}
    session = Mock()
    session.get.return_value = response
    return session


def page(payload=PAYLOAD):
    return '<script class="ds:1">AF_initDataCallback({key: "ds:1", data:' + payload + ', sideChannel: {}});</script>'


def test_raw_json_and_query_are_preserved():
    session = session_for(page())
    result = FastFlightsCollector(session, 17).collect(search(), "2026-09-04T00:00:00Z")
    assert result.raw_body == PAYLOAD.encode()
    assert result.raw == json.loads(PAYLOAD)
    assert result.raw_record_count == 1
    assert result.observations == []
    assert result.response_headers == {"content-type": "text/html"}
    kwargs = session.get.call_args.kwargs
    assert kwargs["timeout"] == 17
    assert kwargs["params"]["curr"] == "CAD"
    assert kwargs["params"]["gl"] == "ca"
    from base64 import b64decode
    from fast_flights.pb.flights_pb2 import Info
    query = Info.FromString(b64decode(kwargs["params"]["tfs"]))
    assert query.data[0].from_airport.airport == "YYZ"
    assert query.data[0].to_airport.airport == "PEK"
    assert query.data[0].date == "2026-11-12"
    assert query.data[0].HasField("max_stops")
    assert query.data[0].max_stops == 0
    assert list(query.data[0].airlines) == ["AC"]
    assert query.seat == 2
    assert query.trip == 2
    assert len(query.passengers) == 2


@pytest.mark.parametrize("records", [None, []])

BODY = b'{ "search_parameters": {"currency": "CAD"}, "unknown": 1.00 }\n'


class Collector:
    def __init__(self):
        self.calls = 0

    def collect(self, request, fetched_at):
        self.calls += 1
        return ProviderResult(
            "serpapi",
            request,
            json.loads(BODY),
            [],
            raw_body=BODY,
            response_status=200,
            response_headers={"content-type": "application/json"},
        )


class RawSink:
    def __init__(self, fail_write: bool = False):
        self.fail_write = fail_write
        self.documents = []
        self.completed = []
        self.failed = []

    def ensure_schema(self):
        pass

    def start_run(self, run_id, started_at):
        pass

    def run_status(self, run_id):
        return None

    def write_document(self, document):
        if self.fail_write:
            raise RuntimeError("database unavailable")
        self.documents.append(document)

    def complete_run(self, run_id, status, manifest, document_count):
        self.completed.append((run_id, status, manifest, document_count))

    def fail_run(self, run_id, error):
        self.failed.append((run_id, error))


def test_provider_response_is_written_only_to_postgres(
    tmp_path, monkeypatch
):
    config_path = tmp_path / "config.yaml"
    write_config(config_path)
    config = load_tracking_config(config_path)
    provider = Collector()
    monkeypatch.setattr(
        "flight_price_tracker.service.make_collectors",
        lambda _settings: {"serpapi": provider},
    )

    sink = RawSink()
    monkeypatch.setattr(
        "flight_price_tracker.service.RawLandingSink.from_env",
        lambda *_args, **_kwargs: sink,
    )

    second = collect(config, settings(tmp_path, config_path, "postgres"), context())

    assert provider.calls == 1
    assert second["reused_requests"] == 0
    assert sink.documents[0].payload_text.encode() == BODY
    assert sink.documents[0].stream == "flight.serpapi.search-response"
    assert sink.documents[0].document_key.startswith("request/")
    assert "provider-key" not in json.dumps(sink.documents[0].metadata)
    assert sink.completed[0][1] == "succeeded"
    assert sink.completed[0][3] == 1
    assert not (tmp_path / "collection_date=2026-08-31").exists()

def test_serpapi_no_results_is_a_successful_empty_search():
    class EmptyResponse:
        status_code = 200
        text = ""
        content = b'{ "error": "Google Flights hasn\'t returned any results for this query." }'
        headers = {"Content-Type": "application/json", "Set-Cookie": "secret"}

        @staticmethod
        def json():
            return {
                "error": "Google Flights hasn't returned any results for this query."
            }

    class EmptySession:
        @staticmethod
        def get(*args, **kwargs):
            return EmptyResponse()

    request = SearchRequest(
        target_id="yyz-pvg",
        origin="YYZ",
        destination="PVG",
        departure_date=date(2026, 11, 1),
        cabin_class="economy",
        currency="CAD",
        adults=1,
        nonstop_only=True,
        country="ca",
        language="en",
    )

    result = SerpApiCollector("key", EmptySession(), 10).collect(
        request, "2026-08-28T20:45:00Z"
    )

    assert result.observations == []
    assert "hasn't returned any results" in result.raw["error"]
    assert result.raw_body == EmptyResponse.content
    assert result.response_headers == {"content-type": "application/json"}
