# Flight Price Tracker

A run-once, execution-location-agnostic flight price collector designed to run from the
same OCI image under:

- `docker run`
- Docker Compose
- Airflow `DockerOperator`
- Airflow `KubernetesPodOperator`

The application has no internal scheduler. One invocation performs a bounded collection,
persists the result, and exits.

## Design goals

1. **One image everywhere.** Docker and Kubernetes execute the same command and container paths.
2. **No node-specific application logic.** Hostnames, credentials, proxy endpoints, and storage
   locations are injected at runtime.
3. **Centralized egress.** HTTP(S) requests can be forced through the shared
   `proton-egress:8888` proxy. The hardened Kubernetes example uses a pod-network
   fail-closed egress rule that permits DNS plus the proxy only.
4. **Centralized persistence.** Durable data is written below
   `/app/output/flight-price-tracker` on the shared tracker landing zone. Do not rely on
   the container filesystem or worker-node-local storage.
5. **Raw + normalized history.** Every successful provider response is retained verbatim,
   then normalized into a stable observation contract.
6. **Idempotent orchestration.** A deterministic `RUN_ID` can be supplied by Airflow. A
   successfully completed run can be skipped on retry.
7. **Cost bounded.** The collector calculates the number of outbound provider searches
   before executing them and refuses to exceed `MAX_REQUESTS_PER_RUN`.
8. **Explicit partial failure.** Successful raw responses are retained, failures are listed
   in the manifest, and `_SUCCESS` is written only when the configured run succeeds.

## Current providers

- **SerpApi Google Flights**: consumer-facing Google Flights search results.
- **Duffel**: structured airline offers through Duffel's Air API.

Provider adapters are intentionally isolated so additional sources can be added without
changing orchestration or storage code.

## Quick start

### 1. Configure targets

Edit:

```text
config/tracked_routes.yaml
```

The production configuration tracks one-way nonstop searches from YYZ to PVG, PEK, and
CAN for every date from 2026-11-01 through 2026-12-31. Past departure dates are removed
from each new plan automatically.

### 2. Create an environment file

```bash
cp .env.example .env
```

Populate at least one provider credential corresponding to the enabled providers.

### 3. Validate and inspect the collection plan

```bash
docker compose -f deploy/docker/docker-compose.yml run --rm tracker validate-config
docker compose -f deploy/docker/docker-compose.yml run --rm tracker plan
```

`plan` performs no provider requests.

### 4. Run one collection

```bash
docker compose -f deploy/docker/docker-compose.yml run --rm tracker collect
```

Or directly:

```bash
docker build -t flight-price-tracker:dev .
docker run --rm \
  --env-file .env \
  -v "$PWD/config/tracked_routes.yaml:/app/config/tracked_routes.yaml:ro" \
  -e OUTPUT_ROOT=/app/output/flight-price-tracker \
  -v "/var/lib/tracker-data:/app/output" \
  flight-price-tracker:dev collect
```

## Output contract

Each run is written under:

```text
/app/output/flight-price-tracker/
└── collection_date=<YYYY-MM-DD>/run_id=<RUN_ID>/
    ├── run_definition.json
    ├── raw/provider=<PROVIDER>/origin=<IATA>/destination=<IATA>/
    │   └── departure_date=<YYYY-MM-DD>/request_key=<SHA256>/
    │       ├── request.json
    │       ├── response.json
    │       ├── observations.ndjson
    │       ├── metadata.json
    │       └── _SUCCESS
    ├── normalized/provider=<PROVIDER>/origin=<IATA>/destination=<IATA>/
    │   └── departure_date=<YYYY-MM-DD>/observations.ndjson
    ├── manifest.json
    └── _SUCCESS
```

Failed runs have `manifest.json` plus `_FAILED`, but never `_SUCCESS`.

A supplied deterministic `RUN_ID`, such as an Airflow logical timestamp, means retries
reuse the same run directory instead of silently creating a second historical observation
window.

## Important API behavior

Flight offers are observations, not immutable facts. Offers can expire quickly, multiple
fare products can exist for the same physical flight, and different providers can expose
different inventories. The tracker therefore stores provider, collection timestamp,
itinerary identity, fare metadata, and price rather than reducing a flight to one
"historical price."

## Production recommendation

The production DAG is `flight_price_tracker_yyz_china`. It runs at minute 17 every four
hours in `America/Toronto`, ends on 2027-01-01, and can select DockerOperator or
KubernetesPodOperator without changing the application contract. Keep it paused until a
SerpApi key is installed and the request budget in `docs/COST_CONTROL.md` is accepted.

# Architecture

## Execution model

The tracker is intentionally a **run-once batch collector**:

```text
start
  -> load and validate configuration
  -> resolve calendar-range/rolling/explicit departure dates
  -> calculate request budget
  -> query configured providers
  -> preserve raw responses
  -> normalize offers
  -> apply exact-flight/airline filters
  -> write normalized observations
  -> optionally upsert PostgreSQL
  -> write manifest + _SUCCESS
  -> exit
```

Scheduling belongs to Airflow, not the application.

## Why this boundary

Flight-price collection does not require a continuously resident process. Keeping the
application run-once provides:

- deterministic collection windows
- natural retries
- easy Docker/Kubernetes parity
- lower idle resource use
- simpler deployment and shutdown behavior
- explicit success/failure semantics

## Components

### Configuration

`config.py` parses environment settings and `tracked_routes.yaml`.

The YAML defines *what* to collect. Environment variables define *how/where* the same
image executes.

### Provider adapters

`collectors/serpapi.py` and `collectors/duffel.py` own provider-specific request/response
logic. They return the same `PriceObservation` domain model.

Nothing outside an adapter should depend on a provider's native schema.

### Filtering

Provider-side filters are used when available to save quota and response volume. The
canonical filtering layer is still applied after normalization, especially for exact
flight numbers that an upstream search API may not support directly.

### Landing zone

The landing zone is the durable system-of-record for collection output.

The collector always keeps raw provider JSON before considering the run complete.
Normalized NDJSON is derived from those raw responses.

### PostgreSQL

PostgreSQL is optional. It is a query-serving sink, not the only copy of source data.
`STORAGE_MODE=both` gives raw/normalized landing-zone output plus relational query access.

If Kubernetes is configured with strict proxy-only pod egress, direct PostgreSQL access
must either be explicitly allowed or the Kubernetes execution should stay
`STORAGE_MODE=landing_zone` and let a downstream local load process populate PostgreSQL.

## Idempotency

Airflow should set:

```text
RUN_ID=<logical UTC timestamp>
```

The run directory becomes deterministic. When `_SUCCESS` already exists and
`SKIP_SUCCESSFUL_RUN=true`, a retry exits without collecting a second observation.

Within PostgreSQL, `(run_id, record_key)` is unique.

## Failure semantics

A provider/date request is one collection unit.

- Successful raw responses are written immediately.
- Failures are accumulated into `manifest.json`.
- `_SUCCESS` is emitted only when the run satisfies the configured failure policy.
- `_FAILED` marks an unsuccessful run.
- With `FAIL_ON_PARTIAL=true`, any exhausted provider request causes a non-zero process exit.

This preserves evidence from partial runs while preventing downstream consumers from
mistaking them for complete snapshots.

## Deterministic logical-run contract

`RunContext` separates immutable logical identity (`RUN_ID`, `LOGICAL_AT`, `ANCHOR_DATE`) from `attempt_started_at`. The latter is observability-only. Durable runs are keyed by `/app/output/flight-price-tracker/collection_date=<DATE>/run_id=<RUN_ID>/`; the immutable `run_definition.json` binds that ID to logical time, anchor, application version, tracking-config SHA256, canonical-plan SHA256, and complete request definitions. A mismatch fails before provider calls.

Each canonical request has a SHA256 `request_key` and its own checkpoint directory. Completed checkpoints are validated and reused on retry; only missing units are fetched. Provider observation timestamps remain the actual fetch timestamps. Final normalized NDJSON is rebuilt from checkpoints in deterministic order, and `_SUCCESS` is published last and makes the run immutable.

# Cost and Request Control

Flight search APIs are usually metered. A configuration that appears small can multiply
quickly.

## Request formula

For the current implementation:

```text
requests per run =
sum over enabled targets (
    resolved departure dates
    x enabled providers
)
```

Example:

```text
2 routes
x 90 departure dates
x 2 providers
x 6 runs/day
= 2,160 provider searches/day
```

## Deployed 2026 tracking plan

Before November, the configured three one-way routes expand to:

```text
3 routes x 61 departure dates x 1 provider = 183 searches/run
183 x 6 four-hour runs/day = 1,098 searches/day
```

At six runs per day from 2026-08-28 through 2026-12-31, the full schedule is over
100,000 SerpApi searches. The daily count declines during November and December because
past departure dates are skipped. Confirm the provider plan/quota and expected bill
before unpausing the DAG.

## Hard guard

Before making any network request, the application compares its plan with:

```text
MAX_REQUESTS_PER_RUN
```

If the plan exceeds the limit, the entire run fails before consuming quota.

## Recommended rollout

1. Install the provider credential without placing it in source control.
2. Run one controlled collection and validate raw/normalized data quality.
3. Measure actual provider request usage and latency.
4. Unpause the four-hour DAG only after accepting the calculated consumption.
5. Add Duffel only where cross-source comparison is worth doubling request volume.

## Collection cadence

Pricing does not need uniform cadence at every booking horizon.

A future optimization is adaptive cadence, for example:

```text
90-180 days before departure: 1/day
30-89 days:                  2/day
7-29 days:                   4/day
0-6 days:                    6/day
```

Keep that optimization in orchestration/configuration rather than converting the
application into a permanent scheduler.

## Deep search

SerpApi `deep_search=true` is intentionally configurable per target. It can provide
closer parity with browser Google Flights results but costs more latency and potentially
more provider resources. Do not enable it globally without validating the benefit.

# Data Contract

## Why the observation is not just "flight + price"

A flight can have multiple simultaneous prices because of:

- provider/source
- cabin
- fare product
- baggage/refund rules
- point of sale
- passenger count
- available inventory
- codeshare/marketing carrier
- itinerary construction

The normalized record therefore retains enough identity to avoid collapsing distinct
offers into one misleading price.

## Normalized observation

Each line in a Hive-partitioned
`normalized/provider=*/origin=*/destination=*/departure_date=*/observations.ndjson`
file contains:

| Field | Meaning |
|---|---|
| `provider` | `serpapi`, `duffel`, etc. |
| `collected_at` | UTC observation timestamp |
| `target_id` | Stable configured tracking target |
| `search_origin` | Requested origin IATA |
| `search_destination` | Requested destination IATA |
| `search_departure_date` | Requested local departure date |
| `cabin_class` | Requested cabin |
| `currency` | Price currency |
| `total_amount` | Displayed/offer total |
| `base_amount` | Base fare when provider exposes it |
| `tax_amount` | Tax amount when provider exposes it |
| `provider_offer_id` | Provider-specific ephemeral offer/token where available |
| `itinerary_signature` | Stable hash of segment identity and times |
| `total_duration_minutes` | Total known itinerary duration |
| `stops` | Number of connections |
| `fare_brand` | Fare brand when reliably available |
| `segments` | Ordered physical/marketing flight segments |
| `source_bucket` | Provider-specific result grouping |
| `provider_metadata` | Additional source fields retained without polluting core schema |
| `record_key` | Deterministic record identity within a run |

## Segment

Each segment contains:

- origin/destination
- local departure/arrival timestamps as returned by the provider
- duration
- marketing carrier code/name
- operating carrier code/name when available
- normalized flight number
- aircraft when available

## Raw contract

Raw API JSON is never reshaped before persistence. This matters because upstream schemas
and the normalized contract can evolve later.

SerpApi represents some valid Google Flights searches with no matching itinerary as an
`error` field saying that Google Flights returned no results. The collector persists and
checkpoints that response as a successful empty search; other provider errors still fail
the request.

## Recommended downstream modeling

A dbt layer can derive:

1. `stg_flight_price_observations`
2. `int_flight_itinerary_prices`
3. `gld_current_flight_prices`
4. `gld_flight_price_history`
5. `gld_flight_price_changes`
6. `gld_booking_window_statistics`

For historical analysis, compare observations by a stable target/itinerary signature and
lead time:

```text
days_to_departure = search_departure_date - collected_at::date
```

Do not join solely on flight number because the same flight number recurs on different
dates and schedules can change.

# Deployment

## Prerequisites

Common:

- reachable centralized HTTP CONNECT proxy if `REQUIRE_PROXY=true`
- provider credentials
- durable landing-zone directory
- immutable built image

Docker:

- external `proton-egress` Docker network
- proxy container/service reachable as `proton-egress:8888`
- shared landing-zone host path

Kubernetes:

- existing `private-apps` namespace and `registry-runner` service account
- `flight-price-tracker-config` ConfigMap
- `flight-price-tracker-secrets` Secret
- existing `proton-egress` Service + EndpointSlice
- existing bound `tracker-output` RWX PVC
- application image available to the worker node

## Docker validation

```bash
cp .env.example .env
# populate keys and host output path as needed

docker compose -f deploy/docker/docker-compose.yml build
docker compose -f deploy/docker/docker-compose.yml run --rm tracker validate-config
docker compose -f deploy/docker/docker-compose.yml run --rm tracker plan
docker compose -f deploy/docker/docker-compose.yml run --rm tracker collect
```

## Kubernetes preparation

The cluster-wide namespace, registry pull secret, proxy endpoint, and shared PVC already
exist. Apply only the application ConfigMap:

```bash
kubectl apply -f deploy/k8s/base/configmap.yaml
```

Create the provider Secret from a mode-restricted file without putting the key on a
command line:

```bash
kubectl -n private-apps create secret generic flight-price-tracker-secrets \
  --from-file=serpapi-api-key=/home/g/.config/flight-price-tracker/serpapi-api-key \
  --dry-run=client -o yaml | kubectl apply -f -
```

Verify prerequisites before running anything:

```bash
kubectl -n private-apps get pvc tracker-output
kubectl -n private-apps get configmap flight-price-tracker-config
kubectl -n private-apps get secret flight-price-tracker-secrets
```

It must be `Bound`.

Verify proxy name resolution/reachability from a disposable test pod or a controlled
validation job before enabling scheduled collection.

Airflow's KubernetesPodOperator supplies the digest-pinned image and full hardened Pod
template; no independent CronJob is enabled in production.

## Scheduling ownership

Choose one scheduler:

### Airflow

Preferred when this data feeds an existing data pipeline, needs dependencies, retries,
backfills, or downstream dbt work.

Do not enable an independent Kubernetes CronJob for the same target/cadence unless
duplicate provider requests are intentional.

## Airflow backend switch

The production DAG uses:

```text
FLIGHT_COLLECTION_OPERATOR=docker
```

or:

```text
FLIGHT_COLLECTION_OPERATOR=kubernetes
```

The switch changes placement/orchestration, not application behavior.

## Production image workflow

1. Build once.
2. Run tests.
3. Push image.
4. Record digest.
5. Deploy the same digest to Docker/Airflow and Kubernetes/Airflow.
6. Change configuration independently from image code where practical.

## Backfills

A historical API backfill is not assumed. To reproduce a *collection run* with a past
anchor date:

```bash
python -m flight_price_tracker plan \
  --config config/tracked_routes.yaml \
  --anchor-date 2026-08-28
```

That changes which future departure dates are searched today; it does not recreate prices
that existed on August 28. Historical prices only exist if they were actually observed
and persisted at that time.

## Installed Airflow schedule

`flight_price_tracker_yyz_china` runs at `17 */4 * * *` in
`America/Toronto`, with `catchup=False`, one active run, and an end date of
2027-01-01. The DAG remains paused until credentials and provider consumption are
approved.

## Logical-run values

Airflow is the canonical production scheduler. Both DockerOperator and
KubernetesPodOperator pass exactly `RUN_ID`, `LOGICAL_AT`, and `ANCHOR_DATE`, derived
from `dag_run.logical_date or dag_run.start_date` for Airflow 3 manual-run compatibility.
The run ID and timestamp use UTC; the anchor date uses `America/Toronto` so an evening
run does not prematurely discard the current local departure date.

## Hardened KPO contract

The DAG imports `FlightTrackerSettings` and `kubernetes_pod_template()` from `orchestration/airflow/flight_tracker_task.py`. The reusable Pod template mirrors the standalone Job: output preflight, fail-closed Proton egress init, restricted `base` container, RWX `/app/output`, read-only tracked routes, bounded `/tmp` and `/run`, explicit resources, dedicated service account with token automount disabled, and role-based `worker|control-plane|any` placement.

# Network and Storage Policy

This repository follows the same portability principle as the existing scraper pattern:
the application must not care whether it runs on the local Docker host or a Kubernetes
worker.

## Stable container contract

Both execution modes use:

```text
configuration: /app/config/tracked_routes.yaml
output root:   /app/output/flight-price-tracker
proxy:         http://proton-egress:8888
command:       python -m flight_price_tracker collect
UID/GID:       1000/1000
```

Only the orchestrator's mounting/network implementation changes.

## Docker

The Compose example joins an existing external Docker network called `proton-egress`.
The central proxy is expected to be resolvable as:

```text
proton-egress:8888
```

Durable storage is a host bind mount:

```text
/var/lib/tracker-data -> /app/output
```

The tracker is not allowed to depend on anonymous Docker volumes.

## Kubernetes

### Proxy

Kubernetes receives the same logical hostname through:

```text
Service proton-egress
        +
EndpointSlice -> externally reachable proxy address
```

The application still sees:

```text
http://proton-egress:8888
```

No application code contains the proxy host's physical IP.

### Fail-closed egress

The hardened KubernetesPodOperator template uses an init container in the pod network namespace to set:

```text
OUTPUT policy = DROP
allow loopback
allow established/related
allow DNS
allow TCP to proton-egress:8888
```

The main application container itself has no Linux capabilities and runs read-only as
UID 1000.

This protects against accidentally sending a provider request directly to the internet
when proxy variables are missing or ignored.

`REQUIRE_PROXY=true` adds an application-level configuration check as a second guard.

### Storage

The existing `private-apps/tracker-output` PVC is `ReadWriteMany` and is backed by the
centralized `/var/lib/tracker-data` NFS export. Both runtimes write the dataset at:

```text
canonical host/NFS: /var/lib/tracker-data/flight-price-tracker
physical SSD:       /srv/landing/trackers/flight-price-tracker
container:          /app/output/flight-price-tracker
```

```text
Docker host                     Kubernetes worker
     |                                |
bind mount                         RWX PVC
     |                                |
     +--------- central landing zone -+
```

There is intentionally **no worker-node-local fallback**. If the PVC cannot bind/mount,
the Kubernetes job should not start.

The example static PV is kept separate because the NFS server address is infrastructure
specific.

## PostgreSQL and strict egress

A direct PostgreSQL connection is not HTTP proxy traffic. With the provided strict
Kubernetes iptables policy it will be blocked.

Recommended default:

```text
Kubernetes collector -> shared landing zone
downstream/local job  -> PostgreSQL
```

If direct PostgreSQL writes from Kubernetes become necessary, explicitly add the
database endpoint/port to the pod egress allowlist rather than weakening the policy to
general internet access.

## Secrets

Never place API tokens in:

- image layers
- tracked YAML
- ConfigMaps
- command-line arguments
- repository `.env`

DockerOperator mounts the mode-restricted host key file read-only. KubernetesPodOperator
mounts the `private-apps/flight-price-tracker-secrets` Secret read-only. The application
reads `/run/secrets/serpapi-api-key` in either runtime.

## Image identity

Production orchestration should pin an immutable digest:

```text
registry.example/flight-price-tracker@sha256:...
```

Do not let the Docker path run one mutable `latest` image while Kubernetes runs another.

def airflow_logical_env() -> dict[str, str]:
    logical = "(dag_run.logical_date or dag_run.start_date)"
    return {
        "RUN_ID": "{{ " + logical + ".in_timezone('UTC').strftime('%Y%m%dT%H%M%SZ') }}",
        "LOGICAL_AT": "{{ " + logical + ".in_timezone('UTC').isoformat() }}",
        # Departure dates are local calendar dates at YYZ. Avoid dropping the
        # current Toronto date when UTC has already rolled into tomorrow.
        "ANCHOR_DATE": (
            "{{ "
            + logical
            + ".in_timezone('America/Toronto').strftime('%Y-%m-%d') }}"
        ),
    }


def proxy_environment(settings: FlightTrackerSettings) -> dict[str, str]:
    return {
        "HTTP_PROXY": settings.proxy_url,
        "HTTPS_PROXY": settings.proxy_url,
        "http_proxy": settings.proxy_url,
        "https_proxy": settings.proxy_url,
        "NO_PROXY": "localhost,127.0.0.1",
        "no_proxy": "localhost,127.0.0.1",
    }


def kubernetes_placement_spec(placement: str) -> dict[str, Any]:
    if placement == "worker":
        return {
            "affinity": {
                "nodeAffinity": {
                    "requiredDuringSchedulingIgnoredDuringExecution": {
                        "nodeSelectorTerms": [
                            {
                                "matchExpressions": [
                                    {
                                        "key": CONTROL_PLANE_LABEL,
                                        "operator": "DoesNotExist",
                                    }
                                ]
                            }
                        ]
                    }
                }
            }
        }

    toleration = {
        "key": CONTROL_PLANE_LABEL,
        "operator": "Exists",
        "effect": "NoSchedule",
    }
    if placement == "control-plane":
        return {
            "nodeSelector": {CONTROL_PLANE_LABEL: ""},
            "tolerations": [toleration],
        }
    if placement == "any":
        return {"tolerations": [toleration]}
    raise ValueError(f"unsupported Kubernetes placement: {placement!r}")


def restricted_security_context() -> dict[str, Any]:
    return {
        "runAsNonRoot": True,
        "runAsUser": 1000,
        "runAsGroup": 1000,
        "allowPrivilegeEscalation": False,
        "readOnlyRootFilesystem": True,
        "capabilities": {"drop": ["ALL"]},
        "seccompProfile": {"type": "RuntimeDefault"},
    }

def build_collection_task(
    *,
    task_id: str = "collect_flight_prices",
    settings: FlightTrackerSettings | None = None,
    **operator_kwargs: Any,
) -> Any:
    selected = settings or FlightTrackerSettings.from_env()
    logical_environment = airflow_logical_env()
    common = {
        "task_id": task_id,
        "do_xcom_push": False,
        "execution_timeout": timedelta(hours=3),
        **operator_kwargs,
    }

    if selected.operator == "docker":
        from docker.types import Mount
        from airflow.providers.docker.operators.docker import DockerOperator

        return DockerOperator(
            image=selected.image,
            command=["collect"],
            docker_url=selected.docker_url,
            docker_conn_id=selected.docker_conn_id,
            force_pull=True,
            network_mode=selected.docker_network,
            environment={
                **proxy_environment(selected),
                **logical_environment,
                "TRACKING_CONFIG": APP_CONFIG,
                "OUTPUT_ROOT": APP_OUTPUT_ROOT,
                "SERPAPI_API_KEY_FILE": APP_SECRET,
                "REQUIRE_PROXY": "true",
                "MAX_REQUESTS_PER_RUN": "200",
            },
            mount_tmp_dir=False,
            mounts=[
                Mount(
                    target=APP_CONFIG,
                    source=selected.docker_config_path,
                    type="bind",
                    read_only=True,
                ),
                Mount(
                    target=APP_SECRET,
                    source=selected.docker_serpapi_key_path,
                    type="bind",
                    read_only=True,
                ),
                Mount(
                    target=APP_OUTPUT_MOUNT,
                    source=selected.docker_output_path,
                    type="bind",
                ),
            ],
            auto_remove="success",
            labels={
                "app": "flight-price-tracker",
                "operator": "docker",
            },
            **common,
        )

    from airflow.providers.cncf.kubernetes.operators.pod import (
        KubernetesPodOperator,
    )

    return KubernetesPodOperator(
        name=task_id.replace("_", "-"),
        namespace=selected.kubernetes_namespace,
        image=selected.image,
        arguments=["collect"],
        kubernetes_conn_id=selected.kubernetes_conn_id,
        pod_template_dict=kubernetes_pod_template(selected),
        env_vars=logical_environment,
        image_pull_policy="IfNotPresent",
        get_logs=True,
        log_events_on_failure=True,
        on_finish_action="delete_pod",
        startup_timeout_seconds=300,
        **common,
    )

set -euo pipefail

ROOT="${1:-.}"
OUTPUT="${2:-./flight-price-tracker-combined.txt}"

ROOT="$(cd "$ROOT" && pwd)"
OUTPUT="$(realpath -m "$OUTPUT")"

find "$ROOT" -type f \
  ! -path "$ROOT/.git/*" \
  ! -path "$ROOT/.venv/*" \
  ! -path "$ROOT/__pycache__/*" \
  ! -path "$ROOT/.pytest_cache/*" \
  ! -path "$ROOT/output/*" \
  ! -path "$OUTPUT" \

from __future__ import annotations

from decimal import Decimal
from typing import Any

import requests

from flight_price_tracker.collectors.base import ProviderResult

class DuffelCollector:
    provider_name = "duffel"
    endpoint = "https://api.duffel.com/air/offer_requests"

    def __init__(
        self,
        access_token: str,
        session: requests.Session,
        timeout_seconds: float,
    ) -> None:
        self.access_token = access_token
        self.session = session
        self.timeout_seconds = timeout_seconds

    def collect(self, request: SearchRequest, collected_at: str) -> ProviderResult:
        body = {
            "data": {
                "slices": [
                    {
                        "origin": request.origin,
                        "destination": request.destination,
                        "departure_date": request.departure_date.isoformat(),
                    }
                ],
                "passengers": [{"type": "adult"} for _ in range(request.adults)],
                "cabin_class": request.cabin_class,
                "max_connections": 0 if request.nonstop_only else 1,
            }
        }
        headers = {
            "Accept": "application/json",
            "Content-Type": "application/json",
            "Accept-Encoding": "gzip",
            "Duffel-Version": "v2",
            "Authorization": f"Bearer {self.access_token}",
        }

        # Duffel recommends making supplier_timeout shorter than the caller's
        # HTTP timeout so completed airline responses can still be returned.
        supplier_timeout_ms = max(
            2000,
            min(60000, int(max(2.0, self.timeout_seconds - 5.0) * 1000)),
        )

        try:
            response = self.session.post(
                self.endpoint,
                params={
                    "return_offers": "true",
                    "supplier_timeout": supplier_timeout_ms,
                    "view": "offers",
                },
                headers=headers,
                json=body,
                timeout=self.timeout_seconds,
            )
        except requests.RequestException as exc:
            raise CollectorError(f"Duffel request failed: {exc}") from exc

        if response.status_code >= 400:
            raise CollectorError(
                f"Duffel returned HTTP {response.status_code}: {response.text[:500]}"
            )

        try:
            raw = response.json()
        except ValueError as exc:
            raise CollectorError("Duffel returned non-JSON content") from exc

        data = raw.get("data")
        if not isinstance(data, dict):
            raise CollectorError("Duffel response does not contain an offer-request object")

        observations = self.normalize(raw, request, collected_at)
        return ProviderResult(
            provider=self.provider_name,
            request=request,
            raw=raw,
            observations=observations,
        )

    @staticmethod
    def _airport_iata(value: Any) -> str:
        if isinstance(value, dict):
            return str(value.get("iata_code") or value.get("iata_city_code") or "")
        return str(value or "")

    @classmethod
    def normalize(
        cls,
        raw: dict[str, Any],
        request: SearchRequest,
        collected_at: str,
    ) -> list[PriceObservation]:
        offer_request = raw.get("data") or {}
        observations: list[PriceObservation] = []

        for offer in offer_request.get("offers") or []:
            segments: list[Segment] = []
            for slice_ in offer.get("slices") or []:
                for segment in slice_.get("segments") or []:
                    marketing = segment.get("marketing_carrier") or {}
                    operating = segment.get("operating_carrier") or {}
                    flight_number = normalize_flight_number(
                        f"{marketing.get('iata_code') or ''}"
                        f"{segment.get('marketing_carrier_flight_number') or ''}"
                    )
                    segments.append(
                        Segment(
                            origin=cls._airport_iata(segment.get("origin")),
                            destination=cls._airport_iata(segment.get("destination")),
                            departure_time_local=segment.get("departing_at"),
                            arrival_time_local=segment.get("arriving_at"),
                            duration_minutes=_iso8601_duration_minutes(
                                segment.get("duration")
                            ),
                            marketing_carrier_code=marketing.get("iata_code"),
                            marketing_carrier_name=marketing.get("name"),
                            operating_carrier_code=operating.get("iata_code"),
                            operating_carrier_name=operating.get("name"),
                            flight_number=flight_number,
                            aircraft=(segment.get("aircraft") or {}).get("name"),
                        )
                    )

            if not segments or offer.get("total_amount") is None:
                continue

            observation = PriceObservation(
                provider=cls.provider_name,
                collected_at=collected_at,
                target_id=request.target_id,
                search_origin=request.origin,
                search_destination=request.destination,
                search_departure_date=request.departure_date.isoformat(),
                cabin_class=request.cabin_class,
                currency=str(
                    offer.get("total_currency") or request.currency
                ).upper(),
                total_amount=Decimal(str(offer["total_amount"])),
                base_amount=(
                    Decimal(str(offer["base_amount"]))
                    if offer.get("base_amount") is not None
                    else None
                ),
                tax_amount=(
                    Decimal(str(offer["tax_amount"]))
                    if offer.get("tax_amount") is not None
                    else None
                ),
                provider_offer_id=offer.get("id"),
                itinerary_signature=build_itinerary_signature(segments),
                total_duration_minutes=sum(
                    segment.duration_minutes or 0 for segment in segments
                )
                or None,
                stops=max(0, len(segments) - 1),
                fare_brand=None,
                segments=segments,
                source_bucket="offers",
                provider_metadata={
                    "expires_at": offer.get("expires_at"),
                    "owner": offer.get("owner"),
                    "live_mode": offer.get("live_mode"),
                    "conditions": offer.get("conditions"),
                    "payment_requirements": offer.get("payment_requirements"),
                },
            ).finalize()
            observations.append(observation)

        return observations


def _iso8601_duration_minutes(value: str | None) -> int | None:
    """Parse the PT#H#M subset used for flight segment durations."""
    if not value or not value.startswith("PT"):
        return None
    body = value[2:]
    hours = 0
    minutes = 0
    if "H" in body:
        hour_text, body = body.split("H", 1)
        hours = int(hour_text or 0)
    if "M" in body:
        minute_text = body.split("M", 1)[0]
        minutes = int(minute_text or 0)
    return hours * 60 + minutes

TRAVEL_CLASS = {
    "economy": 1,
    "premium_economy": 2,
    "business": 3,
    "first": 4,
}


class SerpApiCollector:
    provider_name = "serpapi"
    endpoint = "https://serpapi.com/search"

    def __init__(
        self,
        api_key: str,
        session: requests.Session,
        timeout_seconds: float,
    ) -> None:
        self.api_key = api_key
        self.session = session
        self.timeout_seconds = timeout_seconds

    def collect(self, request: SearchRequest, collected_at: str) -> ProviderResult:
        params: dict[str, Any] = {
            "engine": "google_flights",
            "api_key": self.api_key,
            "departure_id": request.origin,
            "arrival_id": request.destination,
            "outbound_date": request.departure_date.isoformat(),
            "type": 2,
            "travel_class": TRAVEL_CLASS[request.cabin_class],
            "currency": request.currency,
            "adults": request.adults,
            "gl": request.country,
            "hl": request.language,
            "deep_search": str(request.serpapi_deep_search).lower(),
        }
        if request.nonstop_only:
            params["stops"] = 1
        if request.include_airlines:
            params["include_airlines"] = ",".join(request.include_airlines)

        try:
            response = self.session.get(
                self.endpoint,
                params=params,
                timeout=self.timeout_seconds,
            )
        except requests.RequestException as exc:
            raise CollectorError(f"SerpApi request failed: {exc}") from exc

        if response.status_code >= 400:
            raise CollectorError(
                f"SerpApi returned HTTP {response.status_code}: {response.text[:500]}"
            )

        try:
            raw = response.json()
        except ValueError as exc:
            raise CollectorError("SerpApi returned non-JSON content") from exc

        if raw.get("error"):
            error = str(raw["error"])
            # Google Flights reports a valid empty search as an API-level
            # error. For sparse nonstop routes this is expected data, not a
            # failed collection unit. Preserve the response and checkpoint an
            # empty observation list so retries do not spend another credit.
            if "hasn't returned any results" in error.lower():
                return ProviderResult(
                    provider=self.provider_name,
                    request=request,
                    raw=raw,
                    observations=[],
                )
            raise CollectorError(f"SerpApi error: {error}")

        observations = self.normalize(raw, request, collected_at)
        return ProviderResult(
            provider=self.provider_name,
            request=request,
            raw=raw,
            observations=observations,
        )

    @classmethod
    def normalize(
        cls,
        raw: dict[str, Any],
        request: SearchRequest,
        collected_at: str,
    ) -> list[PriceObservation]:
        observations: list[PriceObservation] = []

        for bucket in ("best_flights", "other_flights"):
            for itinerary in raw.get(bucket) or []:
                flights = itinerary.get("flights") or []
                if not flights or itinerary.get("price") is None:
                    continue

                segments: list[Segment] = []
                for flight in flights:
                    departure = flight.get("departure_airport") or {}
                    arrival = flight.get("arrival_airport") or {}
                    flight_number = normalize_flight_number(flight.get("flight_number"))
                    segments.append(
                        Segment(
                            origin=str(departure.get("id") or ""),
                            destination=str(arrival.get("id") or ""),
                            departure_time_local=departure.get("time"),
                            arrival_time_local=arrival.get("time"),
                            duration_minutes=flight.get("duration"),
                            marketing_carrier_code=carrier_code_from_flight_number(
                                flight_number
                            ),
                            marketing_carrier_name=flight.get("airline"),
                            operating_carrier_code=None,
                            operating_carrier_name=None,
                            flight_number=flight_number,
                            aircraft=flight.get("airplane"),
                        )
                    )

                currency = (
                    (raw.get("search_parameters") or {}).get("currency")
                    or request.currency
                )
                price = Decimal(str(itinerary["price"]))

                observation = PriceObservation(
                    provider=cls.provider_name,
                    collected_at=collected_at,
                    target_id=request.target_id,
                    search_origin=request.origin,
                    search_destination=request.destination,
                    search_departure_date=request.departure_date.isoformat(),
                    cabin_class=request.cabin_class,
                    currency=str(currency).upper(),
                    total_amount=price,
                    base_amount=None,
                    tax_amount=None,
                    provider_offer_id=itinerary.get("booking_token"),
                    itinerary_signature=build_itinerary_signature(segments),
                    total_duration_minutes=itinerary.get("total_duration"),
                    stops=max(0, len(segments) - 1),
                    fare_brand=None,
                    segments=segments,
                    source_bucket=bucket,
                    provider_metadata={
                        "type": itinerary.get("type"),
                        "extensions": itinerary.get("extensions") or [],
                        "carbon_emissions": itinerary.get("carbon_emissions"),
                        "price_insights": raw.get("price_insights"),
                    },
                ).finalize()
                observations.append(observation)

        return observations

def env_bool(name: str, default: bool) -> bool:
    value = os.getenv(name)
    if value is None:
        return default
    normalized = value.strip().lower()
    if normalized in {"1", "true", "yes", "on"}:
        return True
    if normalized in {"0", "false", "no", "off"}:
        return False
    raise ConfigurationError(f"{name} must be a boolean, got {value!r}")


def _config_bool(value: Any, field_name: str, default: bool) -> bool:
    if value is None:
        return default
    if isinstance(value, bool):
        return value
    raise ConfigurationError(f"{field_name} must be a YAML boolean")


def _secret_value(value_name: str, file_name: str) -> str | None:
    value = os.getenv(value_name)
    if value:
        return value.strip() or None

    path_value = os.getenv(file_name)
    if not path_value:
        return None
    path = Path(path_value)
    try:
        secret = path.read_text(encoding="utf-8").strip()
    except OSError as exc:
        raise ConfigurationError(f"Cannot read {file_name}={path}: {exc}") from exc
    if not secret:
        raise ConfigurationError(f"{file_name} points to an empty file: {path}")
    return secret

@dataclass(frozen=True)
class DateSpec:
    mode: str
    start_date: date | None = None
    end_date: date | None = None
    start_days_ahead: int | None = None
    end_days_ahead: int | None = None
    step_days: int = 1
    values: tuple[date, ...] = ()

    def resolve(self, anchor: date) -> list[date]:
        if self.mode == "explicit":
            return sorted(set(self.values))
        if self.mode == "calendar_range":
            assert self.start_date is not None
            assert self.end_date is not None
            return [
                self.start_date + timedelta(days=offset)
                for offset in range(
                    0,
                    (self.end_date - self.start_date).days + 1,
                    self.step_days,
                )
            ]
        assert self.start_days_ahead is not None
        assert self.end_days_ahead is not None
        return [
            anchor + timedelta(days=offset)
            for offset in range(
                self.start_days_ahead,
                self.end_days_ahead + 1,
                self.step_days,
            )
        ]

class TrackingTarget:
    id: str
    enabled: bool
    origin: str
    destination: str
    providers: tuple[str, ...]
    cabin_class: str
    currency: str
    adults: int
    nonstop_only: bool
    country: str
    language: str

    skip_past_dates: bool
    include_airlines: tuple[str, ...]
    flight_numbers: tuple[str, ...]

@dataclass(frozen=True)
class TrackingConfig:
    version: int
    targets: tuple[TrackingTarget, ...] = field(default_factory=tuple)

    @property
    def enabled_targets(self) -> tuple[TrackingTarget, ...]:
        return tuple(target for target in self.targets if target.enabled)

    def build_search_requests(self, anchor: date) -> list[tuple[str, SearchRequest]]:
        planned: list[tuple[str, SearchRequest]] = []
        for target in self.enabled_targets:
            for departure_date in target.dates.resolve(anchor):
                if target.skip_past_dates and departure_date < anchor:
                    continue
                request = SearchRequest(
                    target_id=target.id,
                    origin=target.origin,
                    destination=target.destination,
                    departure_date=departure_date,
                    cabin_class=target.cabin_class,
                    currency=target.currency,
                    adults=target.adults,
                    nonstop_only=target.nonstop_only,
                    country=target.country,
                    language=target.language,
                    include_airlines=target.include_airlines,
                    flight_numbers=target.flight_numbers,
                    serpapi_deep_search=target.serpapi_deep_search,
                )
                for provider in target.providers:
                    planned.append((provider, request))
        return planned

    def enforce_request_budget(self, anchor: date, limit: int) -> int:
        count = len(self.build_search_requests(anchor))
        if count > limit:
            raise RequestBudgetExceeded(
                f"Planned {count} provider requests, exceeding MAX_REQUESTS_PER_RUN={limit}. "
                "Reduce enabled targets/date density/providers or raise the limit deliberately."
            )
        return count


def _iata(value: Any, field_name: str) -> str:
    result = str(value or "").strip().upper()
    if not re.fullmatch(r"[A-Z]{3}", result):
        raise ConfigurationError(f"{field_name} must be a 3-letter IATA airport code")
    return result


def _airline_codes(values: Any) -> tuple[str, ...]:
    result = []
    for value in values or []:
        code = str(value).strip().upper()
        if not re.fullmatch(r"[A-Z0-9]{2}", code):
            raise ConfigurationError(f"Invalid airline IATA code: {value!r}")
        result.append(code)
    return tuple(dict.fromkeys(result))


def _date_spec(raw: dict[str, Any]) -> DateSpec:
    mode = str(raw.get("mode", "")).strip().lower()
    if mode == "explicit":
        values = raw.get("values") or []
        if not values:
            raise ConfigurationError("Explicit dates require at least one value")
        try:
            parsed = tuple(date.fromisoformat(str(value)) for value in values)
        except ValueError as exc:
            raise ConfigurationError(f"Invalid explicit date: {exc}") from exc
        return DateSpec(mode="explicit", values=parsed)

    if mode == "calendar_range":
        try:
            start_date = date.fromisoformat(str(raw["start_date"]))
            end_date = date.fromisoformat(str(raw["end_date"]))
            step = int(raw.get("step_days", 1))
        except (KeyError, TypeError, ValueError) as exc:
            raise ConfigurationError(
                "Calendar ranges require ISO start_date/end_date and an integer step_days"
            ) from exc
        if end_date < start_date or step < 1:
            raise ConfigurationError(
                "Calendar ranges require start_date <= end_date and step_days >= 1"
            )
        return DateSpec(
            mode="calendar_range",
            start_date=start_date,
            end_date=end_date,
            step_days=step,
        )

    if mode == "rolling":
        try:
            start = int(raw["start_days_ahead"])
            end = int(raw["end_days_ahead"])
            step = int(raw.get("step_days", 1))
        except (KeyError, TypeError, ValueError) as exc:
            raise ConfigurationError(
                "Rolling dates require integer start_days_ahead/end_days_ahead/step_days"
            ) from exc
        if start < 0 or end < start or step < 1:
            raise ConfigurationError(
                "Rolling dates require 0 <= start_days_ahead <= end_days_ahead and step_days >= 1"
            )
        return DateSpec(
            mode="rolling",
            start_days_ahead=start,
            end_days_ahead=end,
            step_days=step,
        )

    raise ConfigurationError(
        "dates.mode must be calendar_range, explicit, or rolling"
    )


def load_tracking_config(path: Path) -> TrackingConfig:
    if not path.exists():
        raise ConfigurationError(f"Tracking config does not exist: {path}")

    raw = yaml.safe_load(path.read_text()) or {}
    if raw.get("version") != 1:
        raise ConfigurationError("Only tracking config version 1 is supported")

    defaults = raw.get("defaults") or {}
    targets_raw = raw.get("targets") or []
    if not isinstance(targets_raw, list):
        raise ConfigurationError("targets must be a list")

    targets: list[TrackingTarget] = []
    seen_ids: set[str] = set()

    for item in targets_raw:
        merged = {**defaults, **(item or {})}
        target_id = str(merged.get("id", "")).strip()
        if not re.fullmatch(r"[a-z0-9][a-z0-9_-]{1,62}", target_id):
            raise ConfigurationError(
                f"Invalid target id {target_id!r}; use lowercase letters, numbers, _ or -"
            )
        if target_id in seen_ids:
            raise ConfigurationError(f"Duplicate target id: {target_id}")
        seen_ids.add(target_id)

        providers = tuple(
            dict.fromkeys(str(p).strip().lower() for p in merged.get("providers", []))
        )
        if not providers or not set(providers).issubset(ALLOWED_PROVIDERS):
            raise ConfigurationError(
                f"{target_id}: providers must be a non-empty subset of {sorted(ALLOWED_PROVIDERS)}"
            )

        cabin_class = str(merged.get("cabin_class", "economy")).strip().lower()
        if cabin_class not in ALLOWED_CABINS:
            raise ConfigurationError(
                f"{target_id}: cabin_class must be one of {sorted(ALLOWED_CABINS)}"
            )

        currency = str(merged.get("currency", "CAD")).strip().upper()
        if not re.fullmatch(r"[A-Z]{3}", currency):
            raise ConfigurationError(f"{target_id}: currency must be a 3-letter code")

        adults = int(merged.get("adults", 1))
        if adults < 1 or adults > 9:
            raise ConfigurationError(f"{target_id}: adults must be between 1 and 9")

        flight_numbers = tuple(
            dict.fromkeys(
                value
                for raw_value in merged.get("flight_numbers", [])
                if (value := normalize_flight_number(str(raw_value)))
            )
        )

        targets.append(
            TrackingTarget(
                id=target_id,
                enabled=_config_bool(
                    merged.get("enabled"), f"{target_id}.enabled", True
                ),
                origin=_iata(merged.get("origin"), f"{target_id}.origin"),
                destination=_iata(merged.get("destination"), f"{target_id}.destination"),
                providers=providers,
                cabin_class=cabin_class,
                currency=currency,
                adults=adults,
                nonstop_only=_config_bool(
                    merged.get("nonstop_only"),
                    f"{target_id}.nonstop_only",
                    True,
                ),
                country=str(merged.get("country", "ca")).strip().lower(),
                language=str(merged.get("language", "en")).strip().lower(),
                serpapi_deep_search=_config_bool(
                    merged.get("serpapi_deep_search"),
                    f"{target_id}.serpapi_deep_search",
                    False,
                ),
                skip_past_dates=_config_bool(
                    merged.get("skip_past_dates"),
                    f"{target_id}.skip_past_dates",
                    True,
                ),
                include_airlines=_airline_codes(merged.get("include_airlines")),
                flight_numbers=flight_numbers,
                dates=_date_spec(merged.get("dates") or {}),
            )
        )

    if not targets:
        raise ConfigurationError("At least one target must be configured")

    return TrackingConfig(version=1, targets=tuple(targets))


def validate_provider_credentials(config: TrackingConfig, settings: Settings) -> None:

        for target in config.enabled_targets

        )

        raise ConfigurationError(

        )

def canonical_json_bytes(value: Any) -> bytes:
    return json.dumps(value, ensure_ascii=False, sort_keys=True, separators=(',', ':')).encode('utf-8')

def fingerprint(value: Any) -> str:
    return sha256(canonical_json_bytes(value)).hexdigest()

def request_definition(provider: str, request: SearchRequest) -> dict[str, Any]:
    d = asdict(request)
    d['departure_date'] = request.departure_date.isoformat()
    d['include_airlines'] = list(request.include_airlines)
    d['flight_numbers'] = list(request.flight_numbers)
    return {'provider': provider, **d}

def request_key(definition: dict[str, Any]) -> str:
    return fingerprint(definition)

def canonical_plan(planned):
    rows=[request_definition(p,r) for p,r in planned]
    rows.sort(key=lambda x: canonical_json_bytes(x))
    return rows

class PriceObservation:

    collected_at: str

    search_origin: str
    search_destination: str
    search_departure_date: str
    cabin_class: str
    currency: str

    tax_amount: Decimal | None

    record_key: str = ""

    def finalize(self) -> "PriceObservation":
        if not self.record_key:
            identity = {
                "provider": self.provider,
                "target_id": self.target_id,
                "search_departure_date": self.search_departure_date,
                "itinerary_signature": self.itinerary_signature,
                "cabin_class": self.cabin_class,
                "currency": self.currency,
                "total_amount": str(self.total_amount),
                "fare_brand": self.fare_brand,
                "provider_offer_id": self.provider_offer_id,
            }
            self.record_key = sha256(
                json.dumps(identity, sort_keys=True, separators=(",", ":")).encode()
            ).hexdigest()
        return self

    @classmethod
    def from_dict(cls, payload: dict[str, Any]) -> "PriceObservation":
        data = dict(payload)
        data["total_amount"] = Decimal(data["total_amount"])
        data["base_amount"] = None if data.get("base_amount") is None else Decimal(data["base_amount"])
        data["tax_amount"] = None if data.get("tax_amount") is None else Decimal(data["tax_amount"])
        data["segments"] = [Segment(**segment) for segment in data.get("segments", [])]
        return cls(**data)

    def to_dict(self) -> dict[str, Any]:
        payload = asdict(self)
        payload["total_amount"] = str(self.total_amount)
        payload["base_amount"] = None if self.base_amount is None else str(self.base_amount)
        payload["tax_amount"] = None if self.tax_amount is None else str(self.tax_amount)
        return payload


def build_itinerary_signature(segments: list[Segment]) -> str:
    parts = []
    for segment in segments:
        parts.append(
            "|".join(
                [
                    segment.origin,
                    segment.destination,
                    normalize_flight_number(segment.flight_number) or "",
                    segment.departure_time_local or "",
                    segment.arrival_time_local or "",
                ]
            )
        )
    return sha256("||".join(parts).encode()).hexdigest()

from __future__ import annotations

from flight_price_tracker.domain import PriceObservation, SearchRequest, normalize_flight_number


def observation_matches_request(
    observation: PriceObservation,
    request: SearchRequest,
) -> bool:
    if (
        observation.target_id != request.target_id
        or observation.search_origin != request.origin
        or observation.search_destination != request.destination
        or observation.search_departure_date != request.departure_date.isoformat()
        or observation.cabin_class != request.cabin_class
    ):
        return False

    if not observation.segments:
        return False
    if (
        observation.segments[0].origin != request.origin
        or observation.segments[-1].destination != request.destination
    ):
        return False

    if request.nonstop_only and observation.stops != 0:
        return False
    if request.nonstop_only and len(observation.segments) != 1:
        return False

    if request.include_airlines:
        allowed = set(request.include_airlines)
        observed_codes = {
            segment.marketing_carrier_code
            for segment in observation.segments
            if segment.marketing_carrier_code
        }
        if not observed_codes or not observed_codes.issubset(allowed):
            return False

    if request.flight_numbers:
        allowed_numbers = {
            normalize_flight_number(value) for value in request.flight_numbers
        }
        observed_numbers = {
            normalize_flight_number(segment.flight_number)
            for segment in observation.segments
            if segment.flight_number
        }
        if not observed_numbers.intersection(allowed_numbers):
            return False

    return True

from __future__ import annotations

import requests
from requests.adapters import HTTPAdapter
from urllib3.util.retry import Retry


def build_session(retries: int) -> requests.Session:
    retry = Retry(
        total=retries,
        connect=retries,
        read=retries,
        status=retries,
        backoff_factor=1.0,
        status_forcelist=(429, 500, 502, 503, 504),
        # Retrying Duffel's POST automatically could create duplicate offer
        # requests after an ambiguous read timeout. SerpApi GETs are safe to
        # retry; Duffel failures are checkpointed and retried by Airflow.
        allowed_methods=frozenset({"GET"}),
        respect_retry_after_header=True,
        raise_on_status=False,
    )
    adapter = HTTPAdapter(max_retries=retry)
    session = requests.Session()
    session.mount("https://", adapter)
    session.mount("http://", adapter)
    # requests automatically honors HTTP_PROXY / HTTPS_PROXY / NO_PROXY.
    return session

class JsonFormatter(logging.Formatter):
    def format(self, record: logging.LogRecord) -> str:
        payload = {
            "timestamp": datetime.now(timezone.utc).isoformat(),
            "level": record.levelname,
            "logger": record.name,
            "message": record.getMessage(),
        }
        for key in ("run_id", "target_id", "provider", "departure_date"):

            if value is not None:
                payload[key] = value
        if record.exc_info:

        return json.dumps(payload, ensure_ascii=False)

    root.handlers.clear()
    root.addHandler(handler)
    root.setLevel(level.upper())

def parse_utc(value: str) -> datetime:
    parsed = datetime.fromisoformat(value.replace('Z', '+00:00'))
    if parsed.tzinfo is None:
        parsed = parsed.replace(tzinfo=timezone.utc)
    return parsed.astimezone(timezone.utc)


def iso_utc(value: datetime) -> str:
    return value.astimezone(timezone.utc).isoformat().replace('+00:00', 'Z')

@dataclass(frozen=True)
class RunContext:
    run_id: str
    logical_at: datetime
    anchor_date: date
    attempt_started_at: datetime

    @classmethod
    def resolve(cls, *, cli_run_id=None, cli_logical_at=None, cli_anchor_date=None, environ=None, now=None):
        env = os.environ if environ is None else environ
        initial = (now or datetime.now(timezone.utc)).astimezone(timezone.utc)
        logical = parse_utc(cli_logical_at or env.get('LOGICAL_AT')) if (cli_logical_at or env.get('LOGICAL_AT')) else initial
        anchor = date.fromisoformat(cli_anchor_date or env.get('ANCHOR_DATE')) if (cli_anchor_date or env.get('ANCHOR_DATE')) else logical.date()
        run_id = cli_run_id or env.get('RUN_ID') or logical.strftime('%Y%m%dT%H%M%S.%fZ')
        return cls(run_id=run_id, logical_at=logical, anchor_date=anchor, attempt_started_at=initial)

    def stable_dict(self):
        return {'run_id': self.run_id, 'logical_at': iso_utc(self.logical_at), 'anchor_date': self.anchor_date.isoformat()}

        "requests": rows,

    values = dict(definition)
    provider = values.pop("provider")
    values["departure_date"] = date.fromisoformat(values["departure_date"])

def collect(
    config: TrackingConfig, settings: Settings, context: RunContext
) -> dict[str, Any]:
    plan = resolved_plan(config, settings, context.anchor_date)
    landing = LandingZone(settings.output_root, context)
    config_sha256 = sha256(settings.config_path.read_bytes()).hexdigest()
    definition = {
        "schema_version": 2,
        **context.stable_dict(),
        "application_version": __version__,
        "tracking_config_sha256": config_sha256,
        "resolved_plan_sha256": fingerprint(plan),
        "requests": [
            {**row, "request_key": request_key(row)} for row in plan
        ],
    }
    if landing.already_successful():
        definition_sha256 = landing.ensure_definition(definition)
        if settings.skip_successful_run:
            return {
                "run_id": context.run_id,
                "status": "skipped_already_successful",
                "run_dir": str(landing.run_dir),
                "run_definition_sha256": definition_sha256,
            }
        raise ValueError(
            "The run is already complete and immutable; "
            "set a different RUN_ID to collect another observation"
        )

    validate_provider_credentials(config, settings)
    definition_sha256 = landing.ensure_definition(definition)
    collectors = make_collectors(settings)
    observations = []
    failures = []
    reused = 0
    executed = 0

    for item in definition["requests"]:
        key = item["request_key"]
        request_definition = {
            name: value for name, value in item.items() if name != "request_key"
        }
        if landing.checkpoint_complete(key, request_definition):
            observations.extend(
                landing.read_checkpoint_observations(key, request_definition)
            )
            reused += 1
            continue

        provider, request = _search_request(request_definition)
        fetched_at = iso_utc(utc_now())
        try:
            result = collectors[provider].collect(request, fetched_at)
            accepted = [
                observation
                for observation in result.observations
                if observation_matches_request(observation, request)
            ]
            landing.write_checkpoint(
                key,
                request_definition,
                result.raw,
                accepted,
                {
                    "request_key": key,
                    "logical_at": iso_utc(context.logical_at),
                    "provider_fetched_at": fetched_at,
                    "attempt_started_at": iso_utc(context.attempt_started_at),
                    "provider_observation_count": len(result.observations),
                    "accepted_observation_count": len(accepted),
                },
            )
            observations.extend(accepted)
            executed += 1
        except Exception as exc:  # preserve successful checkpoints for retry
            logger.exception("Collection request %s failed", key)
            failures.append(
                {
                    "request_key": key,
                    "provider": provider,
                    "error_type": type(exc).__name__,
                    "error": str(exc),
                }
            )

    normalized_paths = landing.write_observations(observations)
    if not failures:
        status = "success"
    elif observations:
        status = "partial_failure"
    else:
        status = "failed"

    manifest = {
        "schema_version": 3,
        "run_id": context.run_id,
        "logical_at": iso_utc(context.logical_at),
        "anchor_date": context.anchor_date.isoformat(),
        "attempt_started_at": iso_utc(context.attempt_started_at),
        "run_definition_sha256": definition_sha256,
        "status": status,
        "planned_requests": len(plan),
        "completed_requests": len(plan) - len(failures),
        "reused_requests": reused,
        "executed_requests": executed,
        "failed_requests": len(failures),
        "observation_count": len(observations),
        "storage_mode": settings.storage_mode,
        "failures": failures,
        "files": [landing.file_entry(path) for path in normalized_paths],
    }

    if settings.storage_mode in {"postgres", "both"}:
        from flight_price_tracker.storage.postgres import PostgresSink

        postgres = PostgresSink(settings.database_url or "")
        postgres.ensure_schema()
        postgres.write_observations(context.run_id, observations)
        postgres.write_run_manifest(
            context.run_id,
            {**manifest, "collected_at": iso_utc(context.logical_at)},
        )

    manifest_path = landing.write_manifest(manifest)
    should_fail = bool(failures) and (
        settings.fail_on_partial or not observations
    )
    if should_fail:
        landing.mark_failed()
    else:
        landing.mark_success()

    return {
        **manifest,
        "manifest_path": str(manifest_path),
        "run_dir": str(landing.run_dir),
        "exit_success": not should_fail,
    }

def safe_component(value: str) -> str:
    cleaned = re.sub(r"[^A-Za-z0-9._-]+", "_", value.strip())
    if not cleaned or cleaned in {".", ".."}:
        raise StorageError(f"Unsafe path component: {value!r}")
    return cleaned


def hive_component(key: str, value: str) -> str:
    return f"{key}={safe_component(value)}"


def atomic_write_bytes(path: Path, payload: bytes) -> None:
    path.parent.mkdir(parents=True, exist_ok=True)
    descriptor, temporary = tempfile.mkstemp(prefix=f".{path.name}.", dir=path.parent)
    temporary_path = Path(temporary)
    try:
        with os.fdopen(descriptor, "wb") as handle:
            handle.write(payload)
            handle.flush()
            os.fsync(handle.fileno())
        os.replace(temporary_path, path)
    except Exception:
        temporary_path.unlink(missing_ok=True)
        raise


def sha256_file(path: Path) -> str:
    digest = sha256()
    with path.open("rb") as handle:
        for chunk in iter(lambda: handle.read(1024 * 1024), b""):
            digest.update(chunk)
    return digest.hexdigest()

        return self.success_path.exists()

    def assert_mutable(self) -> None:
        if self.success_path.exists():
            raise StorageError(f"Completed run is immutable: {self.run_dir}")

    def ensure_definition(self, definition: dict[str, Any]) -> str:
        payload = canonical_json_bytes(definition)
        digest = sha256(payload).hexdigest()
        self.run_dir.mkdir(parents=True, exist_ok=True)
        if self.definition_path.exists():
            if self.definition_path.read_bytes() != payload:
                raise StorageError(
                    "Existing run_definition.json differs for the same logical run"
                )
        else:
            self.assert_mutable()
            atomic_write_bytes(self.definition_path, payload)
        return digest

    def request_dir(self, key: str, definition: dict[str, Any]) -> Path:
        return (
            self.run_dir
            / "raw"
            / hive_component("provider", str(definition["provider"]))
            / hive_component("origin", str(definition["origin"]))
            / hive_component("destination", str(definition["destination"]))
            / hive_component("departure_date", str(definition["departure_date"]))
            / hive_component("request_key", key)
        )

    def checkpoint_complete(
        self, key: str, definition: dict[str, Any]
    ) -> bool:
        directory = self.request_dir(key, definition)
        required = [
            directory / "request.json",
            directory / "response.json",
            directory / "observations.ndjson",
            directory / "metadata.json",
            directory / "_SUCCESS",
        ]
        if not all(path.exists() for path in required):
            return False
        try:
            if json.loads((directory / "request.json").read_text()) != definition:
                return False
            json.loads((directory / "response.json").read_text())
            json.loads((directory / "metadata.json").read_text())
            self.read_checkpoint_observations(key, definition)
            return True
        except (OSError, ValueError, TypeError, KeyError):
            return False

    def write_checkpoint(
        self,
        key: str,
        definition: dict[str, Any],
        raw: dict[str, Any],
        observations: Iterable[PriceObservation],
        metadata: dict[str, Any],
    ) -> None:
        self.assert_mutable()
        directory = self.request_dir(key, definition)
        directory.mkdir(parents=True, exist_ok=True)
        atomic_write_bytes(directory / "request.json", canonical_json_bytes(definition))
        atomic_write_bytes(
            directory / "response.json",
            json.dumps(raw, ensure_ascii=False, sort_keys=True, indent=2).encode(),
        )
        lines = [
            json.dumps(
                observation.to_dict(),
                ensure_ascii=False,
                sort_keys=True,
                separators=(",", ":"),
            )
            for observation in observations
        ]
        atomic_write_bytes(
            directory / "observations.ndjson",
            (("\n".join(lines) + "\n") if lines else "").encode(),
        )
        atomic_write_bytes(directory / "metadata.json", canonical_json_bytes(metadata))
        atomic_write_bytes(directory / "_SUCCESS", b"")

    def read_checkpoint_observations(
        self, key: str, definition: dict[str, Any]
    ) -> list[PriceObservation]:
        path = self.request_dir(key, definition) / "observations.ndjson"
        return [
            PriceObservation.from_dict(json.loads(line))
            for line in path.read_text().splitlines()
            if line.strip()
        ]

    def write_observations(
        self, observations: Iterable[PriceObservation]
    ) -> list[Path]:
        self.assert_mutable()
        partitions: dict[tuple[str, str, str, str], list[dict[str, Any]]] = (
            defaultdict(list)
        )
        for observation in observations:
            key = (
                observation.provider,
                observation.search_origin,
                observation.search_destination,
                observation.search_departure_date,
            )
            partitions[key].append(observation.to_dict())

        paths: list[Path] = []
        for (provider, origin, destination, departure_date), records in sorted(
            partitions.items()
        ):
            path = (
                self.run_dir
                / "normalized"
                / hive_component("provider", provider)
                / hive_component("origin", origin)
                / hive_component("destination", destination)
                / hive_component("departure_date", departure_date)
                / "observations.ndjson"
            )
            ordered = sorted(records, key=canonical_json_bytes)
            lines = [
                json.dumps(
                    record,
                    ensure_ascii=False,
                    sort_keys=True,
                    separators=(",", ":"),
                )
                for record in ordered
            ]
            atomic_write_bytes(path, ("\n".join(lines) + "\n").encode())
            paths.append(path)
        return paths

    def write_manifest(self, manifest: dict[str, Any]) -> Path:
        self.assert_mutable()
        path = self.run_dir / "manifest.json"
        atomic_write_bytes(
            path,
            json.dumps(manifest, ensure_ascii=False, sort_keys=True, indent=2).encode(),
        )
        return path

    def mark_success(self) -> None:
        self.assert_mutable()
        (self.run_dir / "_FAILED").unlink(missing_ok=True)
        atomic_write_bytes(self.success_path, b"")

    def mark_failed(self) -> None:
        self.assert_mutable()
        atomic_write_bytes(self.run_dir / "_FAILED", b"")

    def file_entry(self, path: Path) -> dict[str, Any]:
        return {
            "path": str(path.relative_to(self.run_dir)),
            "bytes": path.stat().st_size,
            "sha256": sha256_file(path),
        }

def test_serpapi_no_results_is_a_successful_empty_search():
    class EmptyResponse:
        status_code = 200
        text = ""

        @staticmethod
        def json():
            return {
                "error": "Google Flights hasn't returned any results for this query."
            }

    class EmptySession:
        @staticmethod
        def get(*args, **kwargs):
            return EmptyResponse()

    request = SearchRequest(
        target_id="yyz-pvg",
        origin="YYZ",
        destination="PVG",
        departure_date=date(2026, 11, 1),
        cabin_class="economy",
        currency="CAD",
        adults=1,
        nonstop_only=True,
        country="ca",
        language="en",
    )

    result = SerpApiCollector("key", EmptySession(), 10).collect(
        request, "2026-08-28T20:45:00Z"
    )

    assert result.observations == []
    assert "hasn't returned any results" in result.raw["error"]
